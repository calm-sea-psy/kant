필수 1 : PCA와 SVD가 사실 같은 계산이라는 것 확인하기

데이터팀은 고객-상품 행렬을 축소하려 합니다. 3장에서는 공분산행렬을 고유분해하는 방식으로 PCA를 구현했는데, 상품이 수천 개가 되면 공분산행렬(상품 수 × 상품 수)을 만드는 것 자체가 부담입니다. 중심화한 데이터 행렬에 SVD를 바로 적용하면 공분산행렬 없이 같은 결과를 얻을 수 있습니다. 두 방법이 정말 같은지 직접 검증합니다.

문제 1-1 : 중심화 후 SVD의 Vᵀ와 PCA 주성분 비교하기

**요구 사항**

1. `M`의 열 평균을 빼서 중심화한 `Mc`를 만들고, 열 평균이 0에 가까운지 확인합니다.
2. `np.linalg.svd(Mc, full_matrices=False)`로 `U`, `S`, `Vt`를 구합니다.
3. `PCA(n_components=5)`를 `M`(중심화 전)에 적합시킵니다. (sklearn은 내부에서 중심화를 수행)
4. `Vt[:5]`와 `pca.components_`를 **절댓값 기준**으로 비교합니다.
5. sklearn이 공분산행렬을 만들지 않고 SVD를 쓰는 이유를 한 문장으로 설명합니다.

문제 1-2 : 특이값에서 설명 분산 계산하기

**요구 사항**

1. `S ** 2 / (n_samples - 1)`을 계산해 `explained_variance_manual`을 만듭니다.
2. `pca.explained_variance_`와 상위 5개를 비교합니다.
3. 설명분산비(`explained_variance / 전체 합`)를 계산해 `pca.explained_variance_ratio_`와 비교합니다.
4. 상위 5개 주성분의 누적 설명분산비를 출력합니다.
5. 특이값이 클수록 해당 방향의 분산이 크다는 관계를 한 문장으로 설명합니다.

필수 2 : 실무 차원 축소 파이프라인 만들기

축소 결과를 다른 팀에 넘기려면 재현 가능한 절차로 정리해야 합니다. 실무 파이프라인은 표준화 → 분해 → 주성분 선택 → 투영 네 단계로 고정되어 있으며, 첫 단계인 표준화를 빠뜨리면 결과가 크게 왜곡됩니다. 파이프라인을 구현하고 표준화의 영향을 직접 확인합니다.

문제 2-1 : 4단계 파이프라인 구현하기

**요구 사항**

1. `StandardScaler`로 `M`을 표준화합니다.
2. 표준화된 데이터에 SVD를 적용합니다.
3. 누적 설명분산비가 80%를 넘는 최소 주성분 개수 `k`를 구합니다.
4. 상위 `k`개 방향으로 데이터를 투영해 `Z`를 만들고 shape을 확인합니다.
5. 같은 `k`로 `PCA(n_components=k)`를 적용한 결과와 절댓값 기준으로 비교합니다.
6. 투영 결과를 2차원 산점도(PC1, PC2)로 그립니다.

문제 2-2 : 표준화를 생략하면 어떻게 되는지 확인하기

**요구 사항**

1. 표준화하지 않고 중심화만 한 데이터와 표준화한 데이터의 PC1 설명분산비를 각각 구해 비교합니다. **다만 이 지표는 표준화 효과를 보여주지 못합니다.** 실제로 돌려 보면 두 값이 사실상 동일하게 나옵니다(UCI 실데이터 기준 약 0.149 대 0.149). 이 사실 자체를 먼저 확인하세요.
2. 표준화의 진짜 효과는 아래 두 지표로 드러납니다. 둘 다 계산해 비교합니다.
    - **PC1 로딩 집중도** `max|Vt[0]|` — 한 상품이 축을 얼마나 독점하는지. UCI 실데이터 기준 표준화 전 약 0.78 대 표준화 후 약 0.26으로 확실하게 갈립니다.
    - **누적 설명분산비 80% 도달에 필요한 `k`** — UCI 실데이터 기준 표준화 전 약 12개 대 표준화 후 약 17개입니다. 표준화 전에는 소수의 축이 분산을 잡고 있다는 뜻입니다.
3. 표준화하지 않은 경우, PC1 방향에서 절댓값이 가장 큰 상위 3개 상품을 찾습니다.
4. 그 상품들의 원본 구매량 표준편차가 전체에서 몇 번째로 큰지 확인합니다.
5. 표준화를 생략하면 무엇이 문제인지 2~3문장으로 작성합니다.

심화 1 : 저랭크 근사로 추천 후보 만들기

추천 시스템은 고객×상품 평점(또는 구매량) 행렬을 저랭크로 분해해, 아직 구매하지 않은 칸의 값을 예측합니다. "적은 수의 잠재 요인만으로 고객과 상품을 설명할 수 있다"는 가정이 곧 저랭크 가정입니다. 앞에서 만든 임베딩을 실제 추천 후보로 이어 봅니다.

문제 3-1 : TruncatedSVD 임베딩으로 유사 고객과 추천 후보 찾기

**요구 사항**

1. `TruncatedSVD(n_components=5)`로 `M`을 저차원 임베딩 `emb`로 변환하고 shape과 설명분산비를 확인합니다.
2. 임베딩 공간에서 코사인 유사도를 계산해 0번 고객과 유사한 상위 5명을 찾습니다. 단, **첫 번째 성분은 제외하고 `emb[:, 1:]`로 계산합니다.** 구매량은 모든 원소가 0 이상이라 첫 특이 방향이 상품 취향이 아닌 "총구매량" 공통 축이 됩니다. 그대로 쓰면 유사도가 전부 0.99 근처로 몰리며(실제 산출 범위 0.991~0.998) 유사 고객을 구분할 수 없습니다. 두 방식의 유사도 범위를 함께 산출해 차이를 확인하세요.
    - 추가 주의: 고객 행을 **L2 정규화하는 방법은 효과가 없습니다.** cosine 유사도는 계산 과정에서 이미 각 벡터를 자신의 길이로 나누므로, 행을 미리 정규화해도 결과가 전혀 바뀌지 않습니다. 유사도가 1 근처로 몰리는 현상을 해소하는 방법은 첫 성분을 제외하는 것입니다.
3. `svd.inverse_transform(emb)`로 저랭크 복원 행렬 `M_approx`를 만듭니다.
4. 0번 고객이 **이미 구매한 상품은 제외**하고, 복원 점수 상위 10개 상품을 추천 후보로 뽑습니다.
5. 추천 후보의 복원 점수와 원본 값(0)을 나란히 표로 출력합니다.
6. 저랭크 복원 점수가 "아직 사지 않았지만 살 만한 상품"의 근거가 되는 이유를 2~3문장으로 작성합니다.
