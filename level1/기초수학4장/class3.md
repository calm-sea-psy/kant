필수 1 : 고객 데이터를 2차원 지도로 만들기

마케팅팀은 캠페인 대상 고객이 어떤 그룹으로 나뉘는지 한눈에 보고 싶어 합니다. 하지만 특성이 여러 개라 그대로는 그릴 수 없습니다. 지금까지 배운 표준화와 PCA를 이어 붙여 고객 데이터를 2차원 지도로 만듭니다.

문제 1-1 : 표준화가 필요한지 데이터로 확인하기

**요구 사항**

1. 원본 특성별 평균과 표준편차를 계산해, 스케일 차이가 얼마나 큰지 확인합니다.
2. 표준편차 최댓값 / 최솟값 비율을 계산합니다.
3. `StandardScaler`로 표준화한 `Xs`를 만들고, 평균이 0·표준편차가 1인지 확인합니다.
4. 표준화 전후 데이터로 각각 `PCA(n_components=2)`를 적용해 PC1 설명분산비를 비교합니다.
5. 표준화를 먼저 해야 하는 이유를 한 문장으로 작성합니다.

문제 1-2 : PCA로 2차원 지도 그리기

**요구 사항**

1. 표준화된 `Xs`에 `PCA(n_components=2)`를 적용해 `Z`를 만듭니다.
2. `Z`의 shape과 두 주성분의 설명분산비, 누적 설명분산비를 출력합니다.
3. 타깃(가입 여부)을 색으로 구분해 산점도를 그립니다.
4. 두 주성분에 가장 크게 기여한 특성 상위 3개씩을 확인합니다.
5. 2차원 지도에서 읽어 낼 수 있는 점과 읽을 수 없는 점을 각각 한 문장씩 작성합니다.

필수 2 : 비슷한 고객을 찾을 때, 원본과 축소 공간 중 무엇을 쓸까

캠페인 담당자는 "이 고객과 비슷한 고객"을 찾아 유사 타깃 캠페인을 만들려 합니다. 원본 고차원 공간에서 계산하면 정밀하지만 느리고, 축소된 2차원 공간에서 계산하면 빠르지만 정보가 일부 손실됩니다. 두 방식을 실제로 비교해 선택 기준을 만듭니다.

문제 2-1 : 원본 공간에서 유사 고객 찾기

**요구 사항**

1. 표준화된 데이터 앞 2000명을 잘라 `Xs_small`을 만듭니다.
2. `cosine_similarity`로 유사도 행렬을 계산하고 계산 시간을 측정합니다.
3. 0번 고객과 유사도가 높은 상위 5명을 찾아 출력합니다.
4. 유사도 행렬의 shape과 메모리 사용량(원소 수)을 확인합니다.
5. 특성이 수백 개로 늘어나면 어떤 부담이 커지는지 한 문장으로 작성합니다.

문제 2-2 : 축소 공간에서 유사 고객 찾고 비교하기

**요구 사항**

1. **시각화용 차원과 유사도 검색용 차원을 분리합니다.** 2차원은 그림을 그리기 위해 생긴 제약이므로 검색에 그대로 쓰면 정밀도가 망가집니다. 누적 설명분산비 80%를 만족하는 `k_search`를 구해 검색용 좌표 `Z_search`를 만들고, 시각화용 2차원 `Z`와 **둘 다** 유사도를 계산합니다.
2. 0번 고객 기준 상위 5명을 찾아 원본 공간 결과와 비교합니다.
3. 두 목록의 겹치는 인원 수를 계산합니다.
4. 두 유사도 행렬 전체의 상관계수를 계산해 얼마나 비슷한 순위를 주는지 확인합니다.
5. **속도 대신 저장 용량으로 비교합니다.** 원본 / 검색용 `k_search`차원 / 시각화용 2차원의 `nbytes`를 표로 정리하고 절감률을 계산합니다. 이 데이터는 수치형 특성이 한 자리수라 **축소해도 계산 시간 이득은 거의 없다는 점**을 함께 확인하세요. 유사도 행렬 계산 비용은 차원 수가 아니라 샘플 수의 제곱이 지배하기 때문입니다.
6. 어떤 상황에서 어느 공간을 써야 하는지 2~3문장으로 작성합니다.

심화 1 : 라이브러리를 믿기 전에 직접 검증하기

파이프라인 결과를 다른 팀에 전달하기 전에, 라이브러리가 실제로 우리가 의도한 계산을 했는지 확인해야 합니다. NumPy로 직접 구현한 결과와 sklearn 결과를 대조하면 내부 동작을 이해하고 결과에 대한 신뢰를 스스로 확보할 수 있습니다.

문제 3-1 : NumPy 직접 구현과 sklearn 결과 대조하기

**요구 사항**

1. 표준화된 `Xs`를 SVD로 분해해 `U`, `S`, `Vt`를 구합니다. 이때 **`full_matrices=False`를 반드시 명시합니다.** 기본값은 `True`이고, 그대로 두면 `U`를 45,211 × 45,211 행렬로 만들려 해 float64 기준 **약 15GB 메모리**를 요구하고 커널이 죽습니다.
2. `Z_manual = U[:, :2] * S[:2]`로 2차원 투영 좌표를 만듭니다.
3. `Z_manual`과 sklearn의 `Z`를 **절댓값 기준**으로 비교합니다.
4. 공분산행렬 고유분해로도 투영해 세 방식(SVD / 고유분해 / sklearn)의 PC1 상관계수를 계산합니다.
5. 설명분산비도 세 방식으로 계산해 표로 비교합니다.
6. 부호가 다르게 나올 수 있는 이유와, 직접 구현·검증이 실무에서 갖는 의미를 2~3문장으로 작성합니다.
