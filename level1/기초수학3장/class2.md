필수 1 : 행렬을 "축 + 배율"로 분해하기

행렬 변환을 여러 번 반복 적용해야 하는 상황(예: 상태 전이를 100번 반복)에서는 행렬 곱을 100번 하는 대신, 행렬을 축과 배율로 분해해 두면 계산이 훨씬 간단해집니다. 이 분해가 행렬 대각화 A = PDP⁻¹이며, 다음 단계의 PCA도 정확히 같은 구조 위에서 동작합니다.

문제 1-1 : A = PDP⁻¹ 구성하고 복원하기

**요구 사항**

1. `A = [[4, 2], [1, 3]]`을 고유분해해 고유값과 고유벡터를 구합니다.
2. 고유벡터를 열로 쌓은 행렬 `P`와, 고유값을 대각선에 배치한 대각행렬 `D`를 만듭니다.
3. `P @ D @ inv(P)`를 계산해 원본 `A`와 같은지 `np.allclose`로 확인합니다.
4. `P`의 행렬식을 계산해 역행렬이 존재하는지 확인합니다.
5. 대각화가 무엇을 무엇으로 바꾸는 것인지 한 문장으로 설명합니다.

문제 1-2 : 대각화로 거듭제곱 계산하고, 불가능한 경우 확인하기

**요구 사항**

1. `A @ A`와 `P @ D**2 @ inv(P)`를 계산해 같은지 확인합니다. (`D`는 대각행렬이므로 대각 원소만 제곱하면 됨)
2. `A`의 10제곱을 두 방식으로 계산해 같은지 확인합니다.
3. `B = [[1, 1], [0, 1]]`을 고유분해하고, 고유값과 고유벡터의 개수·독립성을 확인합니다.
4. 복원을 시도하기 **전에** `np.linalg.matrix_rank`와 `np.linalg.cond`로 고유벡터 행렬의 가역 여부를 사전 판별합니다. 그런 다음 `P @ D @ inv(P)`를 계산해 원본 `B`와 비교합니다.
    - 주의: NumPy는 이 경우 **에러를 내지 않습니다.** `try/except np.linalg.LinAlgError`로 기다려도 예외가 잡히지 않고, 대신 원본과 전혀 다른 값(단위행렬)이 조용히 나옵니다. 그래서 예외를 기다리는 방식이 아니라 `rank`·`cond`로 **사전에** 판별해야 합니다.
5. 대칭행렬(예: 공분산행렬)이 항상 대각화 가능한 이유를 한 문장으로 작성합니다.

필수 2 : 품질 데이터의 핵심 축을 직접 찾아내기

문제 2-1 : PCA를 NumPy로 직접 구현하기

**요구 사항**

1. 표준화된 `Xs`로 공분산행렬을 계산합니다.
2. `np.linalg.eigh`로 고유분해하고 고유값을 **내림차순**으로 정렬합니다. (고유벡터 열 순서도 함께)
3. 상위 2개 고유벡터로 데이터를 투영해 `Z_manual`을 만듭니다.
4. `Z_manual`의 shape과 상위 2개 주성분의 설명분산비(`고유값 / 고유값 합`)를 계산합니다.
5. 투영 결과의 두 축이 서로 상관이 거의 없는지(상관계수 ≈ 0) 확인합니다.

문제 2-2 : sklearn PCA와 결과 비교하기

**요구 사항**

1. `PCA(n_components=2)`를 `Xs`에 적용해 `Z_sklearn`을 구합니다.
2. `pca.explained_variance_ratio_`를 직접 계산한 설명분산비와 비교합니다.
3. `pca.components_`와 직접 구한 고유벡터를 **절댓값 기준**으로 비교합니다.
4. `Z_manual`과 `Z_sklearn`도 절댓값 기준으로 일치하는지 확인합니다.
5. `PCA()`로 **전체 주성분**을 구해, 성분별로 sklearn과 직접 구한 고유벡터의 부호가 같은지 다른지 표로 정리합니다.
    - 주의: 부호 반전은 **항상 일어나는 것이 아니라 성분에 따라 다릅니다.** PC1·PC2는 부호가 그대로 같게 나올 수도 있으므로, 상위 두 개만 보고 "부호 반전은 없다"고 결론 내리지 말고 뒤쪽 성분까지 함께 확인하세요.
6. PCA 결과를 2차원 산점도로 그립니다.
7. 부호가 뒤집혀 나올 수 있는 이유를 한 문장으로 설명합니다.

심화 1 : 몇 개의 축까지 남길 것인가

차원을 2개로 줄이면 시각화는 편하지만 정보 손실이 큽니다. 반대로 너무 많이 남기면 축소의 의미가 없습니다. 실무에서는 누적 설명분산비를 기준으로 목표치(예: 90%)를 정하고 필요한 주성분 개수를 결정합니다.

문제 3-1 : 누적 설명분산비로 차원 수 결정하기

**요구 사항**

1. `PCA()`를 전체 주성분에 대해 적합시키고 `explained_variance_ratio_`를 구합니다.
2. 누적 설명분산비를 계산해 꺾은선 그래프로 그리고, 90% 기준선을 함께 표시합니다.
3. 누적 설명분산비가 각각 80% / 90% / 95%를 넘는 최소 주성분 개수를 구합니다.
4. 원본 특성 수 대비 축소율을 계산해 표로 정리합니다.
5. 표준화를 하지 않은 원본 데이터로 같은 계산을 해 첫 주성분의 설명분산비를 비교합니다.
6. 기준치를 정할 때 고려해야 할 점을 2~3문장으로 작성합니다.
