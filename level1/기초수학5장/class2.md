필수 1 : 센서 기록을 모델이 원하는 형태로 바꾸기

설비 예지보전 모델은 "6개 시점을 한 구간으로 묶은 배치" 형태의 입력을 요구합니다. 지금 데이터는 (레코드 수, 센서 수)인 2차원 표라서 그대로 넣을 수 없습니다. 원소는 그대로 두고 축 구조만 바꾸는 reshape와, 축 순서를 바꾸는 transpose를 구분해 사용합니다.

문제 1-1 : reshape로 배치 텐서 만들기

**요구 사항**

1. `A_small`의 shape과 전체 원소 수를 확인합니다.
2. `(4, 6, 특성 수)` 형태로 reshape한 `T`를 만들고 shape과 원소 수가 보존되었는지 확인합니다.
3. `-1`을 사용해 `A_small.reshape(4, -1)`을 실행하고 두 번째 축 크기가 어떻게 계산되는지 확인합니다.
4. 원소 수가 맞지 않는 reshape(예: `(5, 6, 특성 수)`)를 시도해 오류를 확인합니다.
5. reshape 전후로 첫 번째 원소(`A_small[0, 0]`과 `T[0, 0, 0]`)가 같은지 확인합니다.

문제 1-2 : transpose와 reshape의 차이 확인하기

**요구 사항**

1. `T`의 축 순서를 `(0, 2, 1)`로 바꾼 `T_t`를 만들고 shape을 확인합니다.
2. 같은 목표 shape을 `reshape`로도 만들어 `T_r`을 얻습니다.
3. `T_t`와 `T_r`의 값이 같은지 확인하고, 다르다면 첫 구간의 값을 직접 비교합니다.
4. `T_t`를 다시 `(0, 2, 1)`로 transpose하면 원본 `T`로 복원되는지 확인합니다.
5. transpose와 reshape의 차이를 한 문장으로 정리합니다.

필수 2 : 축을 끼워 넣고, 크기가 다른 배열끼리 계산하기

모델 입력은 항상 batch 축을 요구하는데, 샘플 하나만 추론할 때는 batch 축이 없어 오류가 납니다. 또 센서별 평균·표준편차 벡터를 전체 데이터에 적용할 때도 shape이 다릅니다. expand_dims/squeeze와 broadcasting으로 이런 상황을 해결합니다.

문제 2-1 : expand_dims와 squeeze로 축 조작하기

**요구 사항**

1. `(6, 5)` 크기의 샘플 하나 `sample = T[0]`을 준비하고 shape을 확인합니다.
2. `np.expand_dims(sample, axis=0)`으로 batch 축을 앞에 추가하고 shape을 확인합니다.
3. `axis=1`, `axis=-1`로도 축을 추가해 shape이 어떻게 달라지는지 비교합니다.
4. `np.squeeze`로 크기 1인 축을 제거해 원래 shape으로 돌아오는지 확인합니다.
5. 크기가 1이 아닌 축에 `squeeze`를 시도하면 어떻게 되는지 확인합니다.
6. 값의 개수는 그대로인데 왜 축 개수를 맞춰야 하는지 한 문장으로 설명합니다.

문제 2-2 : broadcasting으로 센서별 표준화 직접 구현하기

**요구 사항**

1. `A_small`의 센서별 평균 `mean`과 표준편차 `std`를 계산하고 shape을 확인합니다. 표준편차는 `A_small.std(axis=0)`, 즉 **`np.std`(ddof=0)** 기준으로 계산합니다.
2. `(A_small - mean) / std`를 계산하고 결과 shape을 확인합니다. (broadcasting)
3. 표준화 후 각 센서의 평균이 0, 표준편차가 1에 가까운지 `np.std`로 확인합니다. (같은 결과를 pandas `.std()`로 확인하면 n=24, ddof=1 때문에 1이 아닌 1.0215가 나옵니다. 반대로 pandas 표준편차로 나눈 뒤 `np.std`로 확인하면 0.9789가 나옵니다.)
4. `mean`을 `(1, 5)`로 명시적으로 reshape한 경우와 결과가 같은지 확인합니다.
5. 잘못된 방향(예: `(24, 1)` 형태의 행 평균)으로 빼면 어떤 결과가 나오는지 확인합니다. 단, `A_small.mean(axis=1)`은 `(24,)`이므로 그대로 빼면 broadcasting 오류가 납니다. `keepdims=True`를 지정해야 `(24, 1)` 형태가 되므로, 순서대로 ① `keepdims` 없이 빼서 오류를 확인 → ② `keepdims=True`로 `(24, 1)`을 만든 뒤 결과를 비교합니다.
6. broadcasting이 어떤 규칙으로 축을 맞추는지 정리합니다.

심화 1 : 행렬곱 결과 shape을 실행 전에 추론하기

모델을 조립할 때는 각 층을 통과한 뒤 shape이 어떻게 변할지 미리 알아야 다음 층을 설계할 수 있습니다. 단일 행렬곱, 배치 행렬곱, broadcasting 행렬곱 세 가지 규칙을 익히면 대부분의 딥러닝 코드를 실행 없이 읽어 낼 수 있습니다.

문제 3-1 : 세 가지 행렬곱의 결과 shape 추론하기

**요구 사항**

1. 다음 세 조합에 대해 **결과 shape을 먼저 예측**해 적습니다.
    - 단일 행렬곱: `(10, 512) @ (512, 256)`
    - 배치 행렬곱: `(32, 10, 512) @ (32, 512, 256)`
    - broadcasting 행렬곱: `(32, 10, 512) @ (512, 256)`
2. 각 조합을 실제로 계산해 예측과 맞는지 확인합니다.
3. 4차원 배치 행렬곱 `(32, 8, 10, 64) @ (32, 8, 64, 10)`의 결과 shape도 예측하고 확인합니다.
4. 안쪽 차원이 맞지 않는 조합 `(32, 10, 512) @ (256, 512)`를 시도해 오류를 확인합니다.
5. 결과를 표로 정리하고, 배치 축과 마지막 두 축이 각각 어떻게 처리되는지 규칙을 작성합니다.
