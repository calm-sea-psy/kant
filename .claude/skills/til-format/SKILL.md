# TIL 서식 규칙

TIL/*.md 는 하루치 학습 정리입니다. 매일 훑어보며 리마인드하고, `til-to-note` 스킬이 이 파일들을 읽어 NOTE 교안으로 재구성합니다. 그래서 **파일마다 구조가 제각각이면 안 됩니다.** 아래 규칙은 이 저장소의 모든 TIL 파일이 실제로 따르는 관례를 고정한 것입니다.

핵심 철학: TIL 은 "GitHub 에서 렌더링해 읽는 문서"가 아니라 "에디터에서 빠르게 훑는 평문 메모"입니다. 그래서 마크다운 장식(`#` 헤더, 백틱, 펜스)을 최소화하고, 대신 번호·들여쓰기라는 순수 텍스트 구조만 씁니다. 예외는 표뿐입니다 — 표는 평문 정렬이 깨지기 쉬워 마크다운 표를 씁니다.

## 규칙

### 1. 절 구조는 번호로만, 마크다운 헤더 금지

- `#`, `##`, `###` 를 쓰지 않습니다. GitHub 에서 h1 이 튀는 것도 싫고, 평문 메모에 헤더 계층은 과합니다.
- 절: `1. 제목` — 0칸(들여쓰기 없음), 파일 최상단이 곧 `1.`
- 소절: `ㄱ) 소제목` — 0칸
- 세부: `a. 항목` — 0칸
- 마커 뒤에는 **항상 공백 한 칸**: `ㄱ)행렬식`(X) → `ㄱ) 행렬식`(O)
- 절 번호는 1부터 순차, 중복 없음. 소절도 `ㄱ) ㄴ) ㄷ) ...` 순서대로.
- `- 개념`, `- 원리` 처럼 대시로 소제목을 만들지 않습니다. 그건 소제목이면 대시를 떼서 평문 라벨로(`개념`), 진짜 열거면 불릿 규칙(아래)을 따릅니다.

### 2. 본문은 0칸

절·소절 아래 설명 문단은 들여쓰기 없이 0칸에서 시작합니다. 마커와 본문이 같은 왼쪽 정렬선에 놓입니다.

### 3. 불릿은 4칸, 중첩은 8칸

```
ㄱ) 소제목
    - 첫 번째 항목
    - 두 번째 항목
        - 중첩된 세부 항목
```

- 최상위 불릿 `    - ` = 정확히 4칸
- 한 단계 더 들어가면 8칸
- `1) 2) 3)` 같은 숫자 열거 목록도 불릿(`    - `)으로 통일합니다. 절 번호(`1.`)와 헷갈리지 않게.
- 1·2·3·5·6·7칸 같은 어중간한 들여쓰기는 없습니다. 항상 0/4/8.

### 4. 코드는 4칸 들여쓰기, 펜스 없음

- ` ```python ` 같은 펜스 코드 블록을 쓰지 않습니다. 대신 코드 블록 전체를 4칸 들여씁니다.
- 언어 태그 없음.
- 코드 블록 앞뒤로 빈 줄 한 줄.

```
ㄷ) PyTorch 에서 시드 고정하기

    import random, numpy as np, torch

    def set_seed(seed: int = 42):
        random.seed(seed)
        torch.manual_seed(seed)
```

- 디렉토리 트리도 코드처럼 4칸 들여씁니다.

### 5. 표는 마크다운 표

평문 공백 정렬 표는 열이 쉽게 어긋나므로 마크다운 표를 씁니다.

```
| 구분 | 설명 |
|---|---|
| 항목 A | 내용 |
| 항목 B | 내용 |
```

- 헤더 행 + `|---|` 구분선 필수. 헤더가 마땅치 않으면 `| 구분 | 설명 |` 처럼 만들어 붙입니다.
- 표 앞뒤로 빈 줄 한 줄.
- 셀 안에서는 공백 한 칸만. `↑ ↓ → ✅ ❌ ≫` 같은 기호는 셀 안에서 그대로 써도 됩니다.

### 6. 인라인 백틱 금지

`nn.Linear`, `torch.load` 같은 식별자도 백틱 없이 평문으로 씁니다. 메모에서 백틱은 시각적 소음입니다.

### 7. 수식은 말로 풀거나 평문 기호로

- `$K$`, `$[0, 1]$` 같은 LaTeX(`$...$`)를 쓰지 않습니다. `K`, `[0, 1]` 로 충분합니다.
- 복잡한 수식은 말로 풀어씁니다. (예: "행렬식은 대각선 곱에서 반대 대각선 곱을 뺀 값")
- `x^2`, `A⁻¹`, `√d_k` 같은 간단한 평문 표기는 허용.

### 8. ASCII 다이어그램·행렬은 그대로 둔다

손으로 그린 행렬 레이아웃, 계산 그래프, 손실곡선, 트리 구조 등은 0칸에서 원본 그대로 유지합니다. 표로 바꾸거나 들여쓰기를 건드리지 않습니다. 이건 "코드"도 "표"도 아닌 그림입니다.

```
A = [1, 2]        A⁻¹ = (1/-2) × [ 4, -2]
    [3, 4]                        [-3,  1]
```

### 9. 파일 첫 줄은 빈 줄이 아니다

파일은 `1. ...` 로 바로 시작합니다. 맨 앞 빈 줄 금지.

### 10. 말투는 평서체로 통일

TIL 은 남에게 보이는 글이 아니라 자기가 빠르게 훑는 메모입니다. 그래서 종결 어미를 **평서체(문어체)** 로 통일합니다.

- 서술: `-다` / `-이다` / `-한다` / `-된다` / `-아니다` (예: "행렬식은 대각선 곱의 차이다", "역전파는 연쇄법칙을 반복 적용한다")
- 개조식 명사 종결도 허용: `-음` / `-함` / `-것` (예: "값이 클수록 민감함", "스케일링 필수")
- 질문 제목은 평서형 물음표: `~인가?` / `~하나?` (예: "왜 권장되지 않나?")
- 금지: 존댓말(`-입니다` / `-습니다` / `-합니다`), 해요체(`-예요` / `-이에요` / `-거든요` / `-어요`), 존대 청유(`~하세요` / `~보시면`)

NOTE/ 교안은 반대로 존댓말 산문입니다(그건 `til-to-note` 스킬 담당). TIL 은 평서체, NOTE 는 존댓말 — 두 계층을 섞지 않습니다.

한 파일 안에서 말투가 섞여 있으면 전부 평서체로 맞춥니다. 종결 어미만 바꾸고 **문장의 내용·표현은 그대로 둡니다.** `-습니다`→`-다`, `-합니다`→`-한다`(단, `가능합니다`·`동일합니다` 같은 형용사는 `-하다`), `-됩니다`→`-된다`, `쓰입니다`→`쓰인다`, `나옵니다`→`나온다` 처럼 어간에 맞춰 활용을 되돌립니다. 불규칙 활용(`부릅니다`→`부른다`, `만듭니다`→`만든다`)에 주의하고, 변환 후 `git diff` 로 활용이 깨진 곳(`동일한다`, `생기다`, `"…"다` 같은 어색한 형태)이 없는지 눈으로 검토합니다.

## 새 TIL 파일을 쓸 때

파일명은 `TIL/YYMMDD.md` (예: `TIL/260827.md`). 위 규칙대로 작성하면 됩니다. 하루에 여러 주제를 다뤄도 한 파일에 `1. 2. 3. ...` 로 이어서 씁니다.

## 기존 TIL 파일을 정리할 때

1. 파일을 통째로 읽습니다.
2. 규칙 위반을 찾아 고칩니다. **내용(문장·설명·의미)은 바꾸지 않습니다.** 명백한 오타(깨진 링크 파편, `$ㅇ` 같은 꼬리 문자, 용어 오타)만 함께 고치고, 무엇을 고쳤는지 보고에 남깁니다.
3. 마크다운 헤더 → 번호 구조 / 펜스 코드 → 4칸 들여쓰기 / 평문 표 → 마크다운 표 / `- 소제목` → 평문 라벨 또는 `ㄱ)` / LaTeX 제거 / 들여쓰기 0·4·8 정규화 / 존댓말·해요체 → 평서체(규칙 10).
4. `python .claude/skills/til-format/scripts/til_lint.py TIL/YYMMDD.md` 로 검증합니다. 위반이 남아 있으면 다시 고칩니다.
5. 이 파일이 이미 NOTE 에 반영돼 있었다면(`NOTE/.manifest.json` 에 존재), 형식만 바뀌었으므로 재동기화는 불필요합니다. 다만 매니페스트 해시가 어긋나 다음 `til-to-note` 스캔에서 "changed" 로 잡히므로, 형식만 고친 경우 다음 명령으로 해시를 갱신해 둡니다:

```
python .claude/skills/til-to-note/scripts/til_manifest.py update YYMMDD.md <그룹명>
```

`<그룹명>` 은 `NOTE/.manifest.json` 에서 그 파일의 기존 `group` 값을 그대로 씁니다.

## 여러 파일을 한꺼번에 정리할 때

파일별로 구조가 다르므로 기계적 일괄 변환은 위험합니다(특히 불릿 재들여쓰기, 표 감지). 파일 하나씩 읽고 재작성하는 편이 안전합니다. 표를 마크다운으로 바꾸는 작업만은 `scripts/plain_to_md_table.py` 로 일괄 처리할 수 있으나, 실행 후 diff 를 반드시 눈으로 검토하세요 — 정의형 목록(`이름 : 값`)이나 ASCII 그림을 표로 오인할 수 있습니다.

## 검증 스크립트

`scripts/til_lint.py [파일...]` — 인자 없으면 `TIL/*.md` 전체.
검사: 마크다운 헤더, 펜스 코드 블록, `$...$` LaTeX, 맨 앞 빈 줄, 구분선 없는 마크다운 표, 마커(`ㄱ)`/`a.`) 뒤 공백 누락, 표 앞뒤 빈 줄 누락, 존댓말·해요체 종결(규칙 10). 위반을 `파일:줄  설명` 형식으로 출력하고, 하나라도 있으면 종료 코드 1.
