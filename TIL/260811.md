1. 지도학습 (Supervised Learning)
정의: 입력(X)과 정답(레이블 y)이 짝지어진 데이터로 학습, 예측 함수를 학습
목표: 새로운 입력에 대해 정답을 예측

대표 문제 유형

ㄱ) 회귀(Regression): 연속값 예측 (예: 집값 예측)

기본 개념
    - 입력 변수(X)와 연속적인 출력 변수(y) 사이의 관계를 학습하는 지도학습 기법
    - 분류가 "어느 범주에 속하는가"를 묻는다면, 회귀는 "값이 얼마인가"를 묻음
    - 예: 면적·방 개수·위치 등의 정보(X)로 집값(y, 연속값)을 예측

학습 원리 — 손실 최소화
모델이 실제값과 예측값의 차이를 줄이도록 파라미터를 조정. 가장 흔한 손실함수는 평균제곱오차(MSE)

| 알고리즘 | 특징 |
|---|---|
| 선형회귀 | 가장 단순, 해석 쉬움 |
| 다항회귀 | 비선형 관계를 다항식으로 표현 |
| 릿지/라쏘 회귀 | 정규화(regularization)로 과적합 방지 |
| 결정트리 회귀 | 비선형·구간별 예측 가능 |
| 랜덤포레스트/그래디언트부스팅 회귀 | 여러 트리를 앙상블, 성능 우수 |
| 신경망 회귀 | 복잡한 비선형 관계 학습 |

평가 지표
    - MSE / RMSE: 오차 제곱 평균(제곱근) — 큰 오차에 민감
    - MAE: 오차 절댓값 평균 — 이상치에 덜 민감
    - R² (결정계수): 모델이 데이터 분산을 얼마나 설명하는지 (0~1, 1에 가까울수록 좋음)

집값 예측 예시로 정리
    - 데이터: [면적, 방 개수, 학군, 역세권 여부, ...] → 실제 거래가
    - 모델: 선형회귀 또는 랜덤포레스트 회귀
    - 학습: 예측 가격과 실제 가격의 MSE를 최소화하도록 가중치 조정
    - 평가: 새로운 집 데이터에 대해 RMSE, R²로 성능 확인
    - 활용: 새 매물의 면적·조건을 넣으면 예상 가격 산출

ㄴ) 분류(Classification): 범주 예측 (예: 스팸 메일 판별)

기본 개념
입력 변수(X)를 미리 정의된 범주(class/label) 중 하나로 매핑하는 지도학습 기법
회귀가 연속값을 예측한다면, 분류는 이산적인 카테고리를 예측
예: 이메일(X) → 스팸/정상(y), 종양 이미지(X) → 양성/악성(y), 손글씨 숫자(X) → 0~9 중 하나(y)

| 유형 | 설명 | 예시 |
|---|---|---|
| 이진 분류(Binary) | 두 클래스 중 하나 | 스팸 여부, 합격/불합격 |
| 다중 클래스(Multi-class) | 셋 이상 클래스 중 하나만 선택 | 손글씨 숫자(0~9), 붓꽃 품종 |
| 다중 레이블(Multi-label) | 하나의 샘플이 여러 클래스에 동시 속함 | 뉴스 기사의 여러 태그(정치+경제) |

학습 원리 — 손실 최소화
회귀의 MSE 대신 분류에는 교차 엔트로피(Cross-Entropy) 손실을 주로 사용

| 알고리즘 | 특징 |
|---|---|
| 로지스틱 회귀 | 단순, 해석 쉬움, 선형 경계 |
| KNN | 가까운 이웃들의 다수결로 분류 |
| 결정트리 | 규칙 기반, 해석 쉬움 |
| SVM | 마진을 최대화하는 경계 탐색, 커널로 비선형 처리 가능 |
| 랜덤포레스트/그래디언트부스팅 | 여러 트리 앙상블, 성능 우수 |
| 나이브 베이즈 | 조건부 확률 기반, 텍스트 분류에 강함 |
| 신경망 | 복잡한 비선형 경계 학습 (소프트맥스로 다중 클래스) |

평가 지표
회귀와 달리 "얼마나 틀렸나"가 아니라 "맞았나/틀렸나"를 다양한 관점에서 봄
혼동행렬(Confusion Matrix): TP, FP, FN, TN 정리

    TP : 실제 Positive 예측 Positive
    FP : 실제 Negative 예측 Positive
    FN : 실제 Positive 예측 Negative
    TN : 실제 Negative 예측 Negative

    - 정확도(Accuracy): 전체 중 맞춘 비율. 클래스 불균형 시 왜곡될 수 있음
    - 정밀도(Precision): 양성이라 예측한 것 중 실제 양성 비율
    - 재현율(Recall): 실제 양성 중 맞게 예측한 비율
    - F1 Score: 정밀도·재현율의 조화평균
    - ROC-AUC: 임계값을 바꿔가며 True Positive Rate 대 False Positive Rate 곡선의 아래 면적

예: 암 진단처럼 놓치면 안 되는 경우(FN이 치명적)는 재현율을 중시, 스팸 필터처럼 정상 메일을 스팸으로 오분류하면 안 되는 경우는 정밀도를 중시

클래스 불균형 문제
예: 사기 거래 탐지 시 정상 거래가 99%, 사기가 1% → 정확도만 보면 오해 소지
대응: 오버샘플링(SMOTE)/언더샘플링, 클래스 가중치 조정, F1·AUC 등 다른 지표 활용

스팸 분류 예시로 정리
    - 데이터: 이메일 텍스트(X) → 스팸(1)/정상(0) 레이블(y)
    - 모델: 로지스틱 회귀 또는 나이브 베이즈
    - 학습: 교차 엔트로피 손실 최소화
    - 평가: 정밀도·재현율·F1로 성능 확인 (정상 메일을 스팸함으로 보내면 안 되므로 정밀도 중시)
    - 활용: 새 이메일이 도착하면 계산 후 임계값 기준으로 분류

2. 비지도학습 (Unsupervised Learning)
정의: 레이블 없는 데이터에서 숨겨진 구조나 패턴을 스스로 찾음
목표: 데이터의 분포, 군집, 구조를 파악
대표 문제 유형

ㄱ) 군집화(Clustering): 비슷한 데이터끼리 그룹화 (예: 고객 세분화)

기본 개념
레이블 없는 데이터에서 유사한 데이터끼리 그룹(군집)으로 묶는 비지도학습 기법
지도학습처럼 "정답"이 없으므로, 데이터 자체의 거리·밀도·분포 구조를 기준으로 그룹을 스스로 발견
예: 고객 구매 패턴(X)으로 비슷한 소비 성향의 고객군을 자동 분류

핵심 아이디어 — "유사도" 정의
군집화는 결국 거리(distance) 또는 유사도(similarity) 를 어떻게 정의하느냐의 문제
(유클리드 거리가 가장 흔하지만, 맨해튼 거리·코사인 유사도 등도 사용)

대표 알고리즘
    - K-means (분할 기반)
    - 계층적 군집화(Hierarchical Clustering)
    - DBSCAN (밀도 기반)
    - GMM (Gaussian Mixture Model, 확률 기반)

군집 개수(K) 정하는 방법
    - 엘보우 기법(Elbow Method): K에 따른 관성(inertia)을 그래프로 그려 급격히 완만해지는 지점 선택
    - 실루엣 계수(Silhouette Score): 각 데이터가 자기 군집과 얼마나 가깝고 다른 군집과 얼마나 먼지 측정 (−1~1, 높을수록 좋음)

평가의 어려움
    - 지도학습처럼 "정답 레이블"이 없어 평가가 애매함
    - 내부 지표(레이블 없이 평가): 실루엣 계수, Davies-Bouldin Index
    - 외부 지표(정답 레이블이 있을 경우만 사용 가능): ARI(Adjusted Rand Index), NMI

고객 세분화 예시로 정리
    - 데이터: [구매 빈도, 평균 결제액, 최근 구매일, ...] (레이블 없음)
    - 전처리: 스케일 차이가 크면 표준화(StandardScaler) 필요 — 거리 기반이라 스케일에 민감
    - 모델: K-means (K=4로 가정) 또는 DBSCAN
    - 실루엣 계수로 최적 K 탐색
    - 결과 해석: 군집별 평균 특성을 보고 "충성 고객", "신규 고객", "이탈 위험 고객" 등 의미 부여
    - 활용: 군집별 맞춤 마케팅 전략 수립

ㄴ) 차원 축소(Dimensionality Reduction): 특징 수를 줄여 시각화·압축 (예: PCA)

기본 개념
데이터의 특징(feature) 개수(차원)를 줄이면서 원래 정보를 최대한 보존하는 비지도학습 기법
목적: 시각화, 계산량 감소, 노이즈 제거, 차원의 저주(Curse of Dimensionality) 완화
예: 수백 개의 유전자 발현 데이터(X) → 2~3차원으로 압축해 시각화

왜 필요한가 — 차원의 저주
    - 차원이 늘어날수록 데이터 간 거리가 모두 비슷해져 군집화·분류 성능이 떨어짐
    - 차원이 늘어날수록 같은 밀도를 유지하려면 필요한 데이터 양이 지수적으로 증가
    - 특징 간 상관관계(redundancy)가 있으면 굳이 모든 차원을 유지할 필요 없음

대표 알고리즘
    - PCA (Principal Component Analysis, 주성분분석)
    - t-SNE (t-distributed Stochastic Neighbor Embedding)
    - UMAP (Uniform Manifold Approximation and Projection)
    - 오토인코더(Autoencoder)

| 방법 | 선형/비선형 | 주 목적 | 새 데이터 적용 | 해석 가능성 |
|---|---|---|---|---|
| PCA | 선형 | 압축, 노이즈 제거 | 가능 (투영행렬 재사용) | 높음 |
| t-SNE | 비선형 | 시각화 | 어려움 | 낮음 |
| UMAP | 비선형 | 시각화, 압축 | 가능 | 낮음~중간 |
| 오토인코더 | 비선형 | 압축, 특징 추출 | 가능 | 낮음 |

활용 사례
    - 전처리: 군집화·분류 전에 PCA로 노이즈·다중공선성 제거 후 모델 성능 향상
    - 시각화: 고차원 데이터를 2D/3D로 축소해 t-SNE/UMAP으로 그려 군집 구조 확인
    - 압축: 이미지·유전자 데이터처럼 특징이 매우 많은 경우 저장·연산 비용 절감

PCA 예시로 정리 (유전자 데이터)
    - 데이터: 샘플 100개 × 유전자 발현량 20,000개 (20,000차원)
    - 전처리: 표준화(평균 0, 분산 1)
    - 공분산 행렬(20,000×20,000)의 고유값 분해 → 고유값 큰 순으로 정렬
    - 상위 2개 주성분으로 투영 → 2D 산점도로 시각화
    - 해석: PC1이 전체 분산의 40%, PC2가 25% 설명 → 두 축만으로 65% 정보 보존하며 샘플 간 유사도 파악

ㄷ) 이상치 탐지(Anomaly Detection)

기본 개념
전체 데이터의 정상적인 패턴에서 크게 벗어난 데이터 포인트(이상치/outlier)를 찾아내는 기법
지도학습으로도 가능하지만(이상 사례에 레이블이 있는 경우), 실무에서는 이상 사례가 극히 드물고 레이블도 없는 경우가 많아 비지도학습으로 접근하는 경우가 많음
예: 신용카드 이상 거래 탐지, 설비 고장 예측, 네트워크 침입 탐지, 제조 불량품 검출

왜 어려운가
    - 극심한 클래스 불균형: 정상 데이터가 99%+ 인 경우가 흔함 → 분류 문제로 풀기 어려움
    - 레이블 부족: 어떤 게 "이상"인지 사전에 정의하기 어렵고, 새로운 유형의 이상치가 계속 등장
    - 정상의 정의가 유동적: 시간에 따라 정상 패턴이 바뀔 수 있음(concept drift, 예: 계절성 소비 패턴)

접근 방식 분류
    - 통계 기반
    - 거리/밀도 기반
    - 트리 기반 — Isolation Forest
    - 확률 기반 — GMM (Gaussian Mixture Model)
    - 재구성 기반 — Autoencoder / PCA
    - One-Class SVM

평가의 어려움과 방법
    - 레이블이 없으면 사람이 직접 검증하거나 도메인 지식으로 판단
    - 레이블이 일부 있다면: Precision-Recall Curve가 정확도보다 유용 (극심한 불균형이라 정확도는 의미 없음)
    - 재현율(놓치는 이상치 최소화) vs 정밀도(오탐 최소화)의 트레이드오프가 특히 중요
    - 예: 암 진단·설비 고장 예측 → 재현율 중시(놓치면 치명적)
    - 예: 스팸 필터·거래 차단 → 정밀도도 함께 고려(오탐이 많으면 신뢰 하락)

신용카드 이상 거래 탐지 예시로 정리
    - 데이터: [거래 금액, 시간, 위치, 가맹점 카테고리, ...] (정상 거래가 99.9%+)
    - 전처리: 스케일링, 시간대별 패턴 특징 추가
    - 모델: Isolation Forest 또는 오토인코더 (정상 거래로만 학습)
    - 이상 점수 계산 → 임계값 초과 거래를 "의심 거래"로 플래깅
    - 평가: 실제 사기로 확인된 소수 레이블로 Precision-Recall 확인
    - 활용: 의심 거래는 자동 차단하거나 사람 검토로 넘김 (완전 자동화보다 반자동 검토 방식이 흔함)

ㄹ) 밀도 추정

기본 개념
관측된 데이터로부터 그 데이터가 따르는 확률분포 자체를 추정하는 비지도학습 기법
군집화·이상치 탐지·차원 축소가 데이터의 "구조"를 요약한다면, 밀도 추정은 데이터가 어디에 얼마나 밀집해 있는지를 확률 함수 형태로 직접 모델링
사실 지금까지 다룬 여러 기법의 밑바탕에 해당: GMM([[군집화]])도, 재구성 오차 기반 [[이상치 탐지]]도 결국 밀도를 (명시적/암묵적으로) 추정하는 것

왜 필요한가
새로운 데이터 포인트가 "얼마나 그럴듯한(likely)" 값인지 정량적으로 판단 가능
이를 통해 파생되는 응용:
    - 이상치 탐지
    - 데이터 생성(generative modeling)
    - 분류

접근 방식
    - 모수적 방법 (Parametric)
    - 비모수적 방법 (Non-parametric)

모수적 vs 비모수적 비교

| 구분 | 모수적(GMM) | 비모수적(KDE) |
|---|---|---|
| 분포 가정 | 필요 (가우시안 혼합) | 불필요 |
| 파라미터 수 | 적음, 고정 | 데이터 수에 비례 (사실상 전체 데이터 저장) |
| 확장성 | 좋음 (대용량에 유리) | 나쁨 (데이터 많을수록 느림) |
| 유연성 | 낮음 (가정과 다르면 왜곡) | 높음 (복잡한 분포도 표현) |
| 고차원 | 상대적으로 강함 | 차원의 저주에 취약 |

다른 비지도학습 기법과의 관계
    - 군집화: GMM은 밀도 추정인 동시에 soft clustering — 각 데이터가 각 성분(군집)에 속할 확률 자체가 밀도 계산의 부산물
    - 이상치 탐지: 추정된 p(x)가 임계값보다 낮은 점을 이상치로 판단 — 사실상 밀도 추정이 이상치 탐지의 이론적 토대
    - 차원 축소: 고차원에서는 밀도 추정 자체가 어려워지므로(차원의 저주), 먼저 PCA 등으로 축소한 뒤 저차원에서 밀도 추정을 수행하는 경우가 많음

신용카드 거래 예시로 정리 (이상치 탐지와 연결)
    - 데이터: 정상 거래들의 [금액, 시간, 위치] (레이블 없음)
    - 모델: GMM(K=3, 성분 3개로 정상 소비 패턴 그룹 표현) 또는 KDE
    - 학습: EM 알고리즘으로 각 가우시안 성분의 평균·공분산·비중 추정 (또는 KDE로 커널 밀도 계산)
    - 새 거래 x*의 p(x*) 계산
    - p(x*)가 매우 낮으면 → 정상 패턴에서 벗어난 거래 → 이상치로 플래깅

3. 데이터 분리: train / valid / test split

모델이 학습에 쓴 데이터로 자기 성능을 평가하면, 답을 미리 보고 시험을 치는 것과 같다. 실제로는 처음 보는 데이터에서 잘 작동해야 하므로, 학습에 쓰지 않은 데이터로 성능을 확인해야 한다.
그래서 데이터를 학습용·검증용·테스트용으로 나눠서, 모델이 처음 보는 데이터에 얼마나 잘 일반화되는지를 정직하게 측정한다.

4. 선형모델: Linear / Logistic Regression

지도학습의 가장 기본이 되는 두 모델로, 입력의 선형결합을 기반으로 한다는 공통점이 있고 목적(회귀 vs 분류)에 따라 출력을 어떻게 변환하느냐가 다르다.

| 구분 | Linear Regression | Logistic Regression |
|---|---|---|
| 예측 대상 | 연속값 | 클래스 확률(0~1) → 임계값으로 분류 |
| 손실 함수 | MSE (평균제곱오차) | Cross-Entropy (교차엔트로피) |
| 용도 | 회귀 | 분류 |

Linear Regression은 "선형결합을 그대로 출력"해 연속값을 예측하고,
Logistic Regression은 "선형결합을 시그모이드에 통과시켜" 확률로 변환해 분류에 사용한다.
같은 뼈대위에 출력 변환과 손실함수만 다르게 얹은 형제 모델이다.

두 모델의 공통 특징
    - 선형성: 특징(feature)과 출력의 관계가 (변환 함수 이전 기준으로) 선형 → 해석이 쉬움, 해당 특징의 영향력을 직접 나타냄
    - 최적화: 둘 다 경사하강법으로 학습 가능, 손실함수가 볼록(convex)해서 전역 최적해 보장
    - 정규화(Regularization): 과적합 방지를 위해 흔히 L1(Lasso)/L2(Ridge) 페널티 추가
    - 한계: 비선형 관계는 잘 표현 못함 → 다항 특징 추가, 커널 기법, 트리/신경망 모델로 확장

언제 쓰는가
    - 데이터가 상대적으로 적고, 해석 가능성(어떤 변수가 얼마나 영향을 미치는지)이 중요할 때 우선 시도
    - 복잡한 모델(랜덤포레스트, 신경망)의 베이스라인으로도 자주 사용

5. KNN: 거리 기반 예측

기본 개념
새로운 데이터를 예측할 때, 학습 데이터 중 가장 가까운 k개의 이웃을 찾아 그들의 값으로 예측하는 알고리즘
"게으른 학습(Lazy Learning)" 이라 불림 — 별도의 학습(파라미터 추정) 과정 없이, 예측 시점에 전체 학습 데이터를 그대로 사용해 계산
지도학습(분류·회귀) 양쪽에 모두 사용 가능하며, 앞서 [군집화]·[밀도 추정]에서도 "거리" 개념이 핵심이었듯 KNN 역시 거리 기반 방법론의 대표주자

작동 원리
    - 새로운 입력이 주어지면 학습 데이터 전체와의 거리를 계산, 거리가 가장 가까운 k개의 이웃을 선택
    - 분류: k개 이웃의 다수결(majority vote)로 클래스 결정
    - 회귀: k개 이웃의 값의 평균(또는 거리 가중 평균)으로 예측

거리(distance) 정의

| 거리 척도 | 특징 |
|---|---|
| 유클리드 거리 | 가장 흔함, 직선 거리 |
| 맨해튼 거리 | 격자형 이동, 이상치에 덜 민감 |
| 민코프스키 거리 | 유클리드(p=2)·맨해튼(p=1)의 일반형 |
| 코사인 유사도 | 텍스트·고차원 희소 데이터에 적합 |

K 값의 영향 — 편향-분산 트레이드오프
    - k가 작으면 (예: k=1): 노이즈에 민감, 결정 경계가 복잡하고 울퉁불퉁함 → 과적합(분산 큼)
    - k가 크면: 여러 이웃을 평균하므로 경계가 매끄러워짐, 하지만 다른 클래스의 영향까지 받아 → 과소적합(편향 큼)
    - 보통 교차검증(cross-validation) 으로 여러 k를 시도해 최적값 선택
    - 이진 분류에서는 동점 방지를 위해 k를 홀수로 선택하는 경우가 많음

전처리가 특히 중요
    - 스케일링 필수: 거리 기반이므로 특징들의 단위·범위가 다르면 큰 값의 특징이 거리를 지배 → 표준화(StandardScaler) 또는 정규화(Min-Max) 필요
    - 예: [나이(0~100), 연봉(0~100,000,000)]을 그대로 쓰면 사실상 연봉만으로 거리가 결정됨
    - 차원의 저주: 차원이 높아질수록 모든 점들 사이의 거리가 비슷해져 "가까운 이웃"의 의미가 희미해짐 → [차원 축소]로 먼저 차원을 줄이는 경우가 많음

(KNN은 이웃 간 거리를 계산해 예측하므로, 값의 범위가 큰 특성이 거리 계산을 압도해 다른 특성이 사실상 무시될 수 있다. 그래서 스케일링으로 모든 특성의 범위를 맞춰주는 것이 거의 필수이다.)

계산 효율 문제와 해결책
    - 예측할 때마다 전체 학습 데이터와 거리를 계산해야 하므로 데이터가 많으면 느림
    - 가속 구조: KD-Tree, Ball Tree (저차원에서 효율적), 근사 최근접 이웃(ANN, 예: HNSW) (고차원 대용량에 사용)

장·단점

| 장점 | 단점 |
|---|---|
| 구현이 단순하고 직관적 | 예측 시점 계산 비용이 큼 (전체 데이터 필요) |
| 학습 과정이 없음 (즉시 적용 가능) | 차원이 높으면 성능 저하 (차원의 저주) |
| 비선형 결정 경계도 자연스럽게 표현 | 스케일링에 민감, 이상치에 취약 |
| 다중 클래스 분류에 자연스럽게 확장 | 클래스 불균형 시 다수 클래스로 편향되기 쉬움 |

분류 vs 회귀 예시
    - 분류 예: 손글씨 숫자 인식 — 새 이미지와 가까운 k=5개의 학습 이미지 라벨 중 다수결로 숫자 결정
    - 회귀 예: 부동산 가격 예측 — 조건이 비슷한 k=5개의 매물 가격의 평균으로 새 매물 가격 추정

다른 기법과의 연결
    - [군집화]의 K-means와 이름은 비슷하지만 목적이 다르다. KNN은 지도학습(레이블 있음, 예측용), K-means는 비지도학습(레이블 없음, 그룹화용)
    - [이상치 탐지]에서 다룬 LOF(Local Outlier Factor)도 KNN의 거리 개념을 그대로 활용한 확장 기법
    - 거리 계산의 스케일 민감성 때문에 실무에서는 KNN 적용 전 표준화 + PCA 전처리를 함께 쓰는 경우가 많음

KNN은 "비슷한 것끼리는 비슷한 답을 가진다"는 단순한 직관을 그대로 알고리즘화한 것으로,
학습 없이 예측 시점에 거리 계산만으로 동작하는 가장 직관적인 지도학습 모델이다.

6. Decision Tree: 규칙 기반 분할

기본 개념
데이터를 "if-then" 규칙으로 반복 분할해 예측하는 모델 — 스무고개처럼 질문을 던지며 답을 좁혀감
분류(Classification Tree)와 회귀(Regression Tree) 모두 가능(CART: Classification And Regression Tree)
예: "면적 > 30평인가?" → "역세권인가?" → ... 순서로 질문해 최종 집값 범주/값을 예측

구조
    - 루트 노드(Root Node): 전체 데이터, 첫 분할 기준
    - 내부 노드(Internal Node): 특정 특징에 대한 분할 조건
    - 가지(Branch): 조건의 참/거짓에 따른 경로
    - 리프 노드(Leaf Node): 최종 예측값 (분류: 클래스, 회귀: 평균값)

트리를 만드는 원리 — 어떤 기준으로 분할할까?
매 노드마다 데이터를 가장 "잘" 나누는 특징과 임계값을 탐욕적(greedy)으로 선택.
"잘 나눈다"는 것은 분할 후 각 자식 노드가 최대한 순수(pure)해지는 것을 의미

트리 생성 알고리즘 (재귀적 분할)
    - 현재 노드에서 가능한 모든 특징 × 임계값 조합을 시도
    - 지니/엔트로피/MSE 감소가 가장 큰 분할 선택
    - 자식 노드 생성, 데이터 분배
    - 각 자식 노드에서 위 과정 반복
    - 정지 조건 도달 시 리프 노드로 확정 (최대 깊이 도달, 노드 내 샘플 수가 너무 적음, 더 이상 불순도 감소 없음 등)

과적합 문제와 대응 — 가지치기(Pruning)
    - 트리를 끝까지 키우면 학습 데이터에 완벽히 맞춰져 극심한 과적합 발생 (모든 리프가 샘플 1개씩까지 분할 가능)
    - 사전 가지치기(Pre-pruning): 트리 생성 중 조건으로 조기 정지
        - max_depth(최대 깊이), min_samples_split(분할 최소 샘플 수), min_samples_leaf(리프 최소 샘플 수) 등 제한
    - 사후 가지치기(Post-pruning): 일단 트리를 완전히 키운 후, 검증 성능이 떨어지지 않는 선에서 불필요한 가지를 제거 (Cost-Complexity Pruning)

| 장점 | 단점 |
|---|---|
| 해석이 매우 쉬움 (규칙을 그대로 시각화·설명 가능) | 과적합되기 쉬움 (특히 깊은 트리) |
| 특징 스케일링 불필요 (거리 기반 아님, KNN과 대조적) | 작은 데이터 변화에도 트리 구조가 크게 바뀜 (불안정성, 분산 큼) |
| 수치형·범주형 데이터 모두 처리 가능 | 선형 경계를 표현하려면 계단식으로 여러 번 분할해야 함(비효율) |
| 비선형 관계, 특징 간 상호작용 자동 포착 | 결정 경계가 축에 평행한 직선(계단 형태)으로 제한 |
| 특징 중요도(feature importance) 계산 가능 | 데이터 불균형 시 다수 클래스로 편향 가능 |

특징 중요도(Feature Importance)
각 특징이 분할에 사용될 때마다 불순도 감소량을 누적해 특징별 중요도 산출
어떤 변수가 예측에 큰 영향을 미치는지 파악 가능 → 해석 가능성이 결정트리의 큰 장점

단일 트리의 한계 → 앙상블로 발전
결정트리는 분산(variance)이 크다는 근본적 약점(데이터가 조금만 바뀌어도 트리 구조가 확 달라짐)
이를 보완하기 위해 여러 트리를 결합하는 앙상블 기법 발전:
    - 랜덤포레스트(Random Forest): 데이터·특징을 무작위로 샘플링한 여러 트리를 만들어 평균/다수결 (배깅 기반) → 분산 감소
    - 그래디언트 부스팅(Gradient Boosting, XGBoost/LightGBM 등): 이전 트리의 오차를 다음 트리가 보완하도록 순차적으로 학습 → 편향·분산 모두 개선, 실무에서 정형 데이터에 매우 강력

분류 vs 회귀 예시
    - 분류 예: 대출 승인 여부 — "연소득 > 5000만원?" → "신용점수 > 700?" → 승인/거절
    - 회귀 예: 집값 예측 — "면적 > 30평?" → "역세권?" → 해당 리프에 속한 매물들의 평균 가격 예측

다른 기법과의 연결
    - KNN처럼 거리 계산이 필요 없어 스케일링에 자유롭다는 점이 대조적 특징
    - 랜덤포레스트·그래디언트부스팅은 지도학습(회귀/분류)에서 실무 성능이 매우 뛰어난 대표 알고리즘군으로, 결정트리를 "약한 학습기(weak learner)"로 사용하는 앙상블의 기초 단위

결정트리는 "질문을 반복해서 답을 좁혀가는" 직관적인 규칙 기반 모델로, 해석은 쉽지만 단일 트리로는 불안정하고 과적합되기 쉬워 실무에서는 랜덤포레스트·그래디언트부스팅 같은 앙상블 형태로 확장해 사용하는 경우가 대부분이다.

7. 비지도학습 대표주자: K-means와 PCA

이 둘은 비지도학습의 양대 축이라 할 수 있는 군집화와 차원 축소를 대표하는 알고리즘이다. 목적은 다르지만 둘 다 "데이터를 더 단순한 형태로 요약한다"는 공통점이 있다.

ㄱ) K-means (군집화)

개념
레이블 없는 데이터를 K개의 그룹(군집)으로 나누는 알고리즘
각 군집은 하나의 중심점(centroid) 으로 대표됨

알고리즘 (반복적 최적화)
    - K개의 중심을 무작위로 초기화
    - 할당 단계: 각 데이터를 가장 가까운 중심에 배정
    - 갱신 단계: 각 군집에 속한 데이터들의 평균으로 중심 재계산
    - 중심이 더 이상 변하지 않을 때까지 할당·갱신 반복

특징
    - K를 사전에 정해야 함 → 엘보우 기법, 실루엣 계수로 결정
    - 유클리드 거리 기반이므로 스케일링 필수 (KNN과 동일한 이유)
    - 구형(spherical)이고 크기가 비슷한 군집에 유리, 비선형·불균일 밀도 군집은 DBSCAN 등이 더 적합

ㄴ) PCA (차원 축소)

개념
고차원 데이터를 정보 손실을 최소화하며 저차원으로 압축
분산이 가장 큰 방향(축) 을 순서대로 찾아 그 축들로 데이터를 투영

알고리즘
    - 데이터를 평균 0으로 중심화
    - 공분산 행렬 Sigma의 고유값 분해
    - 고유값이 큰 순서대로 고유벡터(주성분) 선택
    - 상위 d개 주성분에 투영

고유값이 클수록 해당 축에 정보(분산)가 많이 실림

특징
    - 선형 변환 → 계산 빠르고 해석 가능
    - 고유벡터들이 서로 직교 → 주성분들이 서로 독립적인 정보
    - 비선형 구조는 왜곡 (t-SNE/UMAP/오토인코더가 대안)

| 구분 | K-means | PCA |
|---|---|---|
| 목적 | 데이터를 그룹으로 분할 | 차원(특징 수)을 축소 |
| 출력 | 각 데이터의 군집 라벨 | 저차원으로 투영된 좌표 |
| 핵심 수학 | 거리 최소화(반복 최적화) | 공분산 행렬의 고유값 분해 |
| 결과 형태 | 이산적 (군집 번호) | 연속적 (새 좌표축 값) |
| 스케일링 | 필수 (거리 기반) | 필수 (분산 기반이라 단위 차이에 민감) |
| 하이퍼파라미터 | K (군집 개수) | d (축소할 차원 수) |

함께 쓰이는 이유 — 실무 파이프라인
고차원 데이터를 K-means로 바로 군집화하면 차원의 저주 때문에 거리 계산이 무의미해지는 경우가 많음. 그래서 실무에서는 다음 순서로 함께 사용:
    - PCA로 먼저 차원 축소 (예: 1000차원 → 20차원, 노이즈 제거 + 계산량 감소)
    - 축소된 공간에서 K-means 수행 (거리 계산이 더 의미 있어짐)
    - 필요시 2~3차원까지 추가 축소해 군집 결과를 시각화

예시: 고객 세분화 파이프라인
    - 데이터: 고객별 수백 개의 행동 지표(구매 이력, 클릭 패턴, ...)
    - PCA로 20차원으로 축소 (전체 분산의 90% 보존)
    - K-means(K=5)로 5개 고객 세그먼트 도출
    - PCA로 다시 2차원 투영해 산점도로 세그먼트 시각화 및 검증

PCA는 "연속적인 선형 부분공간"으로, K-means는 "이산적인 점들의 집합"으로 데이터를 근사한다는 점에서
같은 압축 철학의 두 극단이라 볼 수 있다.

8. 모델을 어떻게 고를까: 선택 기준과 다음 연결

ㄱ) 1단계: 문제 유형부터 확정

| 질문 | 답 | 방향 |
|---|---|---|
| 레이블(정답)이 있는가? | 있음 | 지도학습: 회귀 또는 분류 |
| 레이블(정답)이 있는가? | 없음 | 비지도학습: 군집화 / 차원 축소 / 이상치 탐지 / 밀도 추정 |
| 예측 대상이 연속값인가 범주인가? | 연속값 | 회귀 |
| 예측 대상이 연속값인가 범주인가? | 범주 | 분류 |

ㄴ) 2단계: 선택 기준들

a. 데이터 규모
    - 적은 데이터 (수백~수천): 선형모델, KNN, 결정트리 — 복잡한 모델은 과적합 위험
    - 많은 데이터 (수만 이상): 랜덤포레스트, 그래디언트부스팅, 신경망 — 복잡한 패턴 학습 여력

b. 해석 가능성(Interpretability) vs 성능
    - 규제 산업(금융 심사, 의료 진단), 의사결정 근거 설명이 필요한 경우 → 선형모델, 단일 결정트리 (계수/규칙을 그대로 보여줄 수 있음)
    - 성능이 최우선이고 "왜"는 부차적인 경우(추천, 이미지 인식) → 랜덤포레스트, 그래디언트부스팅, 신경망 (블랙박스지만 성능 우수)

c. 데이터의 선형성/비선형성
    - 특징과 타겟의 관계가 대체로 선형 → 선형모델 (Linear/Logistic Regression)로 충분
    - 복잡한 상호작용·비선형 관계 → 트리 기반 앙상블, KNN, 신경망

d. 특징 스케일 민감도
    - 거리 기반(KNN, K-means와 PCA)은 스케일링 필수
    - 트리 기반(Decision Tree, 랜덤포레스트)은 스케일링 불필요 (분할 기준이 순서만 봄)

e. 계산 비용/속도
    - 학습은 빠르지만 예측이 느림: KNN (게으른 학습, 매번 전체 데이터 스캔)
    - 학습은 오래 걸리지만 예측은 빠름: 선형모델, 트리 기반

f. 클래스 불균형 여부
    - 극심한 불균형(사기 탐지 등) → 일반 분류보다 이상치 탐지 관점으로 접근하거나, 클래스 가중치·리샘플링 병행

g. 차원 수
    - 특징이 매우 많고 상관관계가 큼 → 먼저 [차원 축소]로 정리 후 모델링
    - 차원이 높고 희소(sparse)함(텍스트 등) → 정규화 강한 선형모델(Lasso/Ridge)이 의외로 강함

ㄷ) 3단계: 실전 워크플로우 — "베이스라인부터 시작"
    - 베이스라인 확보: 가장 단순한 모델부터 (회귀는 Linear Regression, 분류는 Logistic Regression) — 성능 기준선 확보 + 해석 용이
    - 비선형 모델로 개선 시도: 결정트리 → 랜덤포레스트/그래디언트부스팅
    - 교차검증(Cross-Validation)으로 일반화 성능 확인, 편향-분산 트레이드오프 점검
        - 학습 성능은 높은데 검증 성능이 낮음 → 과적합(분산 큼) → 정규화, 가지치기, 데이터 증강
        - 둘 다 낮음 → 과소적합(편향 큼) → 더 복잡한 모델, 특징 추가
    - 앙상블/튜닝: 하이퍼파라미터 탐색(그리드서치 등), 여러 모델 앙상블

| 상황 | 추천 모델 |
|---|---|
| 빠르고 해석 쉬운 베이스라인 | Linear/Logistic Regression |
| 비선형, 해석도 어느 정도 필요 | Decision Tree |
| 정형 데이터, 최고 성능 원함 | 랜덤포레스트, 그래디언트부스팅(XGBoost 등) |
| 데이터 적고 국소 패턴 중요 | KNN |
| 레이블 없이 그룹 나누기 | K-means, DBSCAN, GMM |
| 레이블 없이 차원 줄이기/시각화 | PCA, t-SNE, UMAP |
| 희귀 이상 사례 탐지 | Isolation Forest, Autoencoder, GMM 기반 밀도 추정 |
| 이미지/텍스트/음성 등 비정형 데이터 | 신경망(딥러닝) |
