0. 스칼라 벡터 행렬
축(axis) 개수로 이해하기

스칼라        : shape = ()        -> 축 0개
벡터 (b)      : shape = (3,)      -> 축 1개 (길이만 있음, 행/열 구분 없음)
행렬 (W)      : shape = (5, 3)    -> 축 2개 (행, 열)

벡터는 길이만 있어서 (3,) 이런 형태로 표시된다.

    b = np.array([1, 2, 3])
    b.shape   # (3,)  <- "원소가 3개 있다"는 정보 하나뿐


1. 역행렬
[[1,2],[2,4]]의 행렬식은 1*4 - 2*2 = 0이므로 역행렬이 존재하지 않는 특이행렬로
행렬식이 0이면 공간이 눌려서 역방향 변환을 만들 수 없다.
곱해서 뺐을때 0 이 나오면 역행렬이 없다.

A = [a, b]        det(A) = a×d - b×c
    [c, d]

det(A) == 0 이면 역행렬이 존재하지 않음

ㄱ) 행렬식
det(A) = 1×4 - 2×3 = -2

ㄴ) 2x2 역행렬 공식
A = [a, b]        A⁻¹ = (1/det(A)) × [ d, -b]
    [c, d]                            [-c,  a]

ㄷ) 2x2 역행렬 풀이
A = [1, 2]
    [3, 4]

A⁻¹ = (1/-2) × [ 4, -2]
                [-3,  1]

     = [ 4/-2, -2/-2]     = [-2,   1 ]
       [-3/-2,  1/-2]       [1.5, -0.5]

ㄹ) 검산

A @ A_inv = [1, 2] @ [-2,   1 ]
            [3, 4]   [1.5, -0.5]

결과 (0,0) 위치: 1×(-2) + 2×1.5 = -2 + 3 = 1
결과 (0,1) 위치: 1×1 + 2×(-0.5) = 1 - 1 = 0
결과 (1,0) 위치: 3×(-2) + 4×1.5 = -6 + 6 = 0
결과 (1,1) 위치: 3×1 + 4×(-0.5) = 3 - 2 = 1

A @ A_inv = [1, 0]  = I
            [0, 1]


2. 단위행렬
정의가 이미 정해진 고정된 행렬
암호화 <-> 복호화 처럼 역행렬이 잘 만들어졌는지 확인하는 방법을 단위행렬이라고 한다.
검산도구로서 A⁻¹이 올바르게 계산됐는지 검산 할때 사용한다.(I = A @ A⁻¹)

4. 행렬의 곱셈

| 연산자 | 이름 | 동작 |
|---|---|---|
| X * W | 원소별 곱셈(element-wise) | 같은 위치끼리 그냥 곱함 — shape이 같아야 함 |
| X @ W | 행렬곱(matrix multiplication) | 행×열 내적 — X의 열 수 = W의 행 수만 맞으면 됨 |

X(8, 5) @ W(5, 3) = 결과(8, 3)
     ↑      ↑
    이 두 숫자(5)가 일치해야 계산 가능, 계산 후 사라짐

X의 각 행(고객 1명, 특성 5개)과
W의 각 열(가중치 세트 1개, 5개 값)을
내적해서 숫자 하나를 만들고,
이걸 8명×3세트 = 24번 반복해서 (8,3) 표로 채운 것이 X @ W다.


5. 비가환

행렬 곱은 앞 행렬의 행과 뒤 행렬의 열을 짝지어 계산하기 때문에 순서를 바꾸면 곱해지는
행과 열의 짝 자체가 달라져 결과가 달라진다.

이를 비교환성(AB≠BA)이라고 부르며, 신경망 레이어의 순서가 중요한 이유도 여기서 비롯된다.
행렬 곱셈에서 곱하는 두 행렬의 순서를 바꾸면 결과가 달라질 수 있다는 성질

6. 선형변환

선형 변환은 반드시 원점을 원점으로 보내야 하는데, 평행이동은 원점까지 함께 이동시켜 T(0) = t ≠ 0이 되므로
동차성이 깨진다.
회전, 스케일링, 반사는 모두 원점을 그대로 두면서 가산성과 동차성을 만족하는 대표적인 선형 변환이다.

8. 완전 연결층(y = XW + b)

입력 5 → 은닉 4 → 출력 2가 되도록 W1, b1, W2, b2 생성했을때

| 단계 | 계산 | shape 변화 | 근거 |
|---|---|---|---|
| 1층 | X(8,5) @ W1(5,4) + b1(4,) | (8,5) → (8,4) | W1의 열 수(4)가 다음 shape의 열이 됨 |
| 2층 | H(8,4) @ W2(4,2) + b2(2,) | (8,4) → (8,2) | W2의 열 수(2)가 최종 출력 열이 됨 |

즉 입력은 열이 되고 1층의 출력 값은 다음 층의 입력값이 된다 최종 출력층은 2가 되어야 되기 때문에
b의 값은 b1(4,) b2(2,) 이 값이 정해진다.

X@W+b 형태의 층을 완전연결층(Fully Connected Layer, FC Layer)이라고 부른다.
다만 "여러 층을 쌓아서"가 아니라, 한 층 안에서 입력과 출력이 연결되는 방식

etc. 은닉층(Hidden Layer)은 "입력도 아니고, 우리가 최종적으로 원하는 출력도 아닌, 중간에서 계산되는 값"

즉, 완전연결층에서 결과값 하나를 구할 때는 연결된 모든 입력값과 모든 파라미터(가중치)가 전부 계산에 참여하고,
그 참여 비중(가중치 크기)이 학습을 통해 조정되면서 AI가 "무엇을 얼마나 중요하게 볼지"를
스스로 결정하게 된다.
