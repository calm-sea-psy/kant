# 지도학습·비지도학습 기초 모델

> 출처 TIL: 260811

## 1. 지도학습(Supervised Learning)이란

입력과 정답(레이블)이 짝지어진 데이터로 학습해서, 새로운 입력에 대한 정답을 예측하는 함수를 만드는 방식입니다. 크게 회귀와 분류 두 가지 문제 유형으로 나뉩니다.

### 1-1. 회귀(Regression): 연속값 예측

입력 변수와 연속적인 출력 변수 사이의 관계를 학습하는 기법입니다. 분류가 "어느 범주에 속하는가"를 묻는다면, 회귀는 "값이 얼마인가"를 묻습니다. 예를 들어 면적·방 개수·위치 같은 정보로 집값(연속값)을 예측하는 문제가 대표적입니다.

학습은 실제값과 예측값의 차이를 줄이는 방향으로 파라미터를 조정하는 방식으로 이루어지며, 가장 흔히 쓰이는 손실 지표는 평균제곱오차입니다.

대표 알고리즘으로는 선형회귀(가장 단순하고 해석이 쉬움), 다항회귀(비선형 관계를 다항식으로 표현), 릿지/라쏘 회귀(정규화로 과적합 방지), 결정트리 회귀(비선형·구간별 예측), 랜덤포레스트·그래디언트부스팅 회귀(여러 트리를 앙상블해 성능 우수), 신경망 회귀(복잡한 비선형 관계 학습)가 있습니다.

평가는 오차 제곱 평균(또는 그 제곱근), 오차 절댓값 평균(이상치에 덜 민감), 결정계수(모델이 데이터의 분산을 얼마나 설명하는지, 1에 가까울수록 좋음) 등을 사용합니다.

### 1-2. 분류(Classification): 범주 예측

입력을 미리 정의된 범주 중 하나로 매핑하는 기법입니다. 회귀가 연속값을 예측한다면 분류는 이산적인 카테고리를 예측합니다. 이메일을 스팸/정상으로 나누거나, 손글씨 숫자를 0~9 중 하나로 분류하는 문제가 대표적입니다.

분류 문제는 두 클래스 중 하나를 고르는 이진 분류, 셋 이상의 클래스 중 하나만 고르는 다중 클래스 분류, 하나의 샘플이 여러 클래스에 동시에 속할 수 있는 다중 레이블 분류로 나뉩니다.

회귀의 평균제곱오차 대신, 분류에는 주로 교차 엔트로피 손실을 사용합니다. 대표 알고리즘으로는 로지스틱 회귀(단순하고 해석 쉬움), KNN(가까운 이웃들의 다수결), 결정트리(규칙 기반), SVM(마진을 최대화하는 경계 탐색), 랜덤포레스트·그래디언트부스팅(여러 트리 앙상블), 나이브 베이즈(조건부 확률 기반, 텍스트 분류에 강함), 신경망(복잡한 비선형 경계 학습)이 있습니다.

분류의 평가는 회귀처럼 "얼마나 틀렸나"가 아니라 "맞았나 틀렸나"를 다양한 관점에서 봅니다. 실제 양성인데 양성으로 맞힌 경우, 실제 음성인데 양성으로 잘못 예측한 경우, 실제 양성인데 음성으로 잘못 예측한 경우, 실제 음성인데 음성으로 맞힌 경우 네 가지 조합을 정리한 혼동행렬이 기본 도구입니다. 이를 바탕으로 전체 중 맞춘 비율(정확도, 클래스 불균형 시 왜곡될 수 있음), 양성이라 예측한 것 중 실제 양성 비율(정밀도), 실제 양성 중 맞게 예측한 비율(재현율), 정밀도와 재현율의 조화평균(F1), 임계값을 바꿔가며 그린 곡선의 아래 면적(ROC-AUC) 등을 계산합니다. 암 진단처럼 놓치면 안 되는 경우는 재현율을, 스팸 필터처럼 정상 메일을 잘못 걸러내면 안 되는 경우는 정밀도를 중시합니다.

정상 거래가 99%, 사기 거래가 1%인 경우처럼 클래스 비율이 크게 치우친 상황에서는 정확도만 보면 오해하기 쉽습니다. 이런 클래스 불균형에는 오버샘플링(SMOTE)이나 언더샘플링, 클래스 가중치 조정, F1·AUC 같은 다른 지표 활용으로 대응합니다.

## 2. 비지도학습(Unsupervised Learning)이란

레이블 없는 데이터에서 숨겨진 구조나 패턴을 스스로 찾아내는 방식입니다. 목표는 데이터의 분포, 군집, 구조를 파악하는 것입니다.

### 2-1. 군집화(Clustering): 비슷한 데이터끼리 묶기

레이블 없는 데이터에서 유사한 데이터끼리 그룹으로 묶는 기법입니다. 지도학습처럼 "정답"이 없으므로, 데이터 자체의 거리나 밀도, 분포 구조를 기준으로 그룹을 스스로 발견합니다. 고객의 구매 패턴으로 비슷한 소비 성향의 고객군을 자동으로 나누는 문제가 대표적입니다.

핵심은 결국 "거리(또는 유사도)를 어떻게 정의하느냐"의 문제이며, 대표 알고리즘으로는 K-means(분할 기반), 계층적 군집화, DBSCAN(밀도 기반), GMM(확률 기반)이 있습니다.

군집의 개수를 정하는 방법으로는, 군집 개수에 따른 군집 내 응집도를 그래프로 그려 급격히 완만해지는 지점을 찾는 엘보우 기법이나, 각 데이터가 자기 군집과 얼마나 가깝고 다른 군집과는 얼마나 먼지를 측정하는 실루엣 계수가 있습니다.

비지도학습은 정답 레이블이 없어 평가가 애매합니다. 레이블 없이 평가하는 내부 지표(실루엣 계수, Davies-Bouldin Index 등)와, 정답 레이블이 있을 때만 쓸 수 있는 외부 지표(ARI, NMI 등)로 나뉩니다.

### 2-2. 차원 축소(Dimensionality Reduction): 특징 수 줄이기

데이터의 특징 개수(차원)를 줄이면서 원래 정보를 최대한 보존하는 기법입니다. 목적은 시각화, 계산량 감소, 노이즈 제거, 그리고 차원이 늘어날수록 데이터 간 거리가 모두 비슷해지고 필요한 데이터 양이 폭발적으로 늘어나는 "차원의 저주" 완화입니다.

대표 알고리즘으로는 PCA(선형, 압축·노이즈 제거에 강하고 새 데이터에도 적용 가능하며 해석 가능성이 높음), t-SNE(비선형, 시각화 전용이며 새 데이터 적용이 어렵고 해석 가능성 낮음), UMAP(비선형, 시각화와 압축 모두 가능), 오토인코더(비선형, 압축·특징 추출용)가 있습니다.

전처리 단계에서 군집화나 분류 전에 PCA로 노이즈와 다중공선성을 제거해 모델 성능을 높이거나, 고차원 데이터를 2~3차원으로 축소해 t-SNE·UMAP으로 시각화하는 데 활용됩니다.

### 2-3. 이상치 탐지(Anomaly Detection)

전체 데이터의 정상적인 패턴에서 크게 벗어난 데이터를 찾아내는 기법입니다. 지도학습으로도 가능하지만, 실무에서는 이상 사례가 극히 드물고 레이블도 없는 경우가 많아 비지도학습으로 접근하는 경우가 많습니다. 신용카드 이상 거래 탐지, 설비 고장 예측, 네트워크 침입 탐지 등이 대표적입니다.

이상치 탐지가 어려운 이유는 정상 데이터가 99% 이상인 극심한 클래스 불균형, 무엇이 "이상"인지 사전에 정의하기 어려운 레이블 부족, 시간에 따라 정상 패턴 자체가 바뀔 수 있다는 점(개념 변화) 때문입니다.

접근 방식은 통계 기반, 거리·밀도 기반, 트리 기반(Isolation Forest), 확률 기반(GMM), 재구성 기반(오토인코더·PCA), One-Class SVM 등으로 나뉩니다.

레이블이 없으면 사람이 직접 검증하거나 도메인 지식으로 판단해야 하고, 레이블이 일부 있다면 극심한 불균형 상황에서는 정확도보다 Precision-Recall 곡선이 더 유용합니다. 놓치는 이상치를 최소화할지(재현율 중시), 오탐을 최소화할지(정밀도 중시)의 트레이드오프가 특히 중요합니다.

### 2-4. 밀도 추정(Density Estimation)

관측된 데이터가 따르는 확률분포 자체를 추정하는 기법입니다. 군집화·이상치 탐지·차원 축소가 데이터의 "구조"를 요약한다면, 밀도 추정은 데이터가 어디에 얼마나 밀집해 있는지를 확률 함수 형태로 직접 모델링합니다. 사실 GMM 기반 군집화나 재구성 오차 기반 이상치 탐지도 결국 밀도를 명시적 또는 암묵적으로 추정하는 것입니다.

접근 방식은 분포의 형태를 가정하고 소수의 파라미터로 표현하는 모수적 방법(예: GMM)과, 분포 형태를 가정하지 않고 데이터 자체를 그대로 활용하는 비모수적 방법(예: 커널 밀도 추정)으로 나뉩니다. 모수적 방법은 대용량에 유리하지만 가정과 실제 분포가 다르면 왜곡되고, 비모수적 방법은 유연하지만 데이터가 많아질수록 느려지고 고차원에서 취약합니다.

## 3. 데이터 분리: train / valid / test

모델이 학습에 쓴 데이터로 자기 성능을 스스로 평가하면, 답을 미리 보고 시험을 치르는 것과 같습니다. 실제로는 처음 보는 데이터에서 잘 작동해야 하므로, 학습에 쓰지 않은 데이터로 성능을 확인해야 합니다. 그래서 데이터를 학습용·검증용·테스트용으로 나누어, 모델이 처음 보는 데이터에 얼마나 잘 일반화되는지를 정직하게 측정합니다.

## 4. 선형모델: 선형회귀와 로지스틱회귀

지도학습의 가장 기본이 되는 두 모델로, 입력을 선형으로 결합한다는 공통점이 있고 목적(회귀 vs 분류)에 따라 출력을 어떻게 변환하느냐만 다릅니다. 선형회귀는 선형결합을 그대로 출력해 연속값을 예측하고, 손실로는 평균제곱오차를 씁니다. 로지스틱회귀는 선형결합을 확률(0~1)로 변환해 분류에 사용하며, 손실로는 교차 엔트로피를 씁니다. 같은 뼈대 위에 출력 변환과 손실 함수만 다르게 얹은 형제 모델이라 할 수 있습니다.

두 모델 모두 특징과 출력의 관계가 선형이라 해석이 쉽고, 경사하강법으로 학습 가능하며 손실 함수가 볼록해서 전역 최적해가 보장됩니다. 과적합 방지를 위해 L1(라쏘)/L2(릿지) 정규화를 흔히 추가합니다. 다만 비선형 관계는 잘 표현하지 못한다는 한계가 있어, 다항 특징 추가나 커널 기법, 트리·신경망 모델로 확장합니다.

데이터가 상대적으로 적고 해석 가능성이 중요할 때 우선 시도하며, 복잡한 모델의 베이스라인으로도 자주 쓰입니다.

## 5. KNN: 거리 기반 예측

새로운 데이터를 예측할 때, 학습 데이터 중 가장 가까운 k개의 이웃을 찾아 그들의 값으로 예측하는 알고리즘입니다. 별도의 학습(파라미터 추정) 과정 없이 예측 시점에 전체 학습 데이터를 그대로 사용해 계산하기 때문에 "게으른 학습"이라 불리며, 분류와 회귀 양쪽에 모두 사용됩니다.

분류에서는 k개 이웃의 다수결로 클래스를 결정하고, 회귀에서는 k개 이웃 값의 평균(또는 거리 가중 평균)으로 예측합니다. 거리를 재는 방식으로는 가장 흔한 유클리드 거리, 격자형 이동을 가정해 이상치에 덜 민감한 맨해튼 거리, 이 둘의 일반형인 민코프스키 거리, 텍스트나 고차원 희소 데이터에 적합한 코사인 유사도 등이 있습니다.

k 값이 작으면 노이즈에 민감해 결정 경계가 복잡해지고 과적합(분산이 큼) 위험이 커지며, k 값이 크면 여러 이웃을 평균내 경계가 매끄러워지는 대신 다른 클래스의 영향까지 받아 과소적합(편향이 큼) 위험이 커집니다. 보통 교차검증으로 여러 k를 시도해 최적값을 선택합니다.

KNN은 거리 기반이므로 전처리가 특히 중요합니다. 특징들의 단위나 범위가 다르면 값이 큰 특징이 거리 계산을 지배해버리기 때문에 표준화나 정규화가 거의 필수입니다. 또한 차원이 높아질수록 모든 점 사이의 거리가 비슷해져 "가까운 이웃"이라는 개념 자체가 희미해지는 차원의 저주 문제도 있어, 차원 축소를 먼저 적용하는 경우가 많습니다.

예측할 때마다 전체 학습 데이터와 거리를 계산해야 하므로 데이터가 많으면 예측이 느려진다는 단점이 있고, 이를 보완하기 위해 KD-Tree, Ball Tree, 근사 최근접 이웃 같은 가속 구조를 사용합니다.

## 6. 결정트리(Decision Tree): 규칙 기반 분할

데이터를 "만약~라면" 형태의 규칙으로 반복 분할해 예측하는 모델로, 스무고개처럼 질문을 던지며 답을 좁혀갑니다. 분류와 회귀 모두 가능합니다.

트리는 전체 데이터를 나타내는 루트 노드, 특정 특징에 대한 분할 조건을 담은 내부 노드, 조건의 참/거짓에 따라 나뉘는 가지, 최종 예측값을 담은 리프 노드로 구성됩니다.

매 노드마다 데이터를 가장 "잘" 나누는 특징과 기준값을 탐욕적으로 선택합니다. "잘 나눈다"는 것은 분할 후 각 자식 노드가 최대한 순수해지는(한 범주로 쏠리는) 것을 의미하며, 이 과정을 반복해 정지 조건(최대 깊이 도달, 노드 내 샘플 수 부족, 더 이상 순도 개선이 없음 등)에 도달하면 리프 노드로 확정합니다.

트리를 끝까지 키우면 학습 데이터에 완벽히 맞춰져 극심한 과적합이 발생합니다. 이를 막기 위해 트리 생성 중 조건으로 조기에 멈추는 사전 가지치기(최대 깊이 제한, 분할·리프 최소 샘플 수 제한 등)와, 일단 트리를 완전히 키운 뒤 검증 성능이 떨어지지 않는 선에서 불필요한 가지를 제거하는 사후 가지치기를 사용합니다.

결정트리는 해석이 매우 쉽고(규칙을 그대로 시각화·설명 가능), 특징 스케일링이 불필요하며(거리 기반이 아니므로 KNN과 대조적), 수치형·범주형 데이터를 모두 처리할 수 있고, 특징 간 상호작용을 자동으로 포착하며, 특징 중요도를 계산할 수 있다는 장점이 있습니다. 반면 과적합되기 쉽고, 데이터가 조금만 바뀌어도 트리 구조가 크게 바뀌는 불안정성(분산이 큼)이 있으며, 결정 경계가 축에 평행한 계단 형태로 제한된다는 단점이 있습니다.

결정트리는 분산이 크다는 근본적 약점이 있어, 이를 보완하기 위해 여러 트리를 결합하는 앙상블 기법(랜덤포레스트, 그래디언트부스팅)으로 발전합니다.

## 7. 비지도학습 대표주자: K-means와 PCA

K-means(군집화)와 PCA(차원 축소)는 비지도학습의 양대 축을 대표하는 알고리즘입니다. 목적은 다르지만 둘 다 "데이터를 더 단순한 형태로 요약한다"는 공통점이 있습니다.

**K-means**는 레이블 없는 데이터를 지정된 개수의 그룹(군집)으로 나누는 알고리즘입니다. 각 군집은 하나의 중심점으로 대표됩니다. 중심을 무작위로 초기화한 뒤, 각 데이터를 가장 가까운 중심에 배정하고, 각 군집에 속한 데이터들의 평균으로 중심을 다시 계산하는 과정을 중심이 더 이상 변하지 않을 때까지 반복합니다. 군집 개수는 미리 정해야 하며 엘보우 기법이나 실루엣 계수로 결정하고, 유클리드 거리 기반이라 스케일링이 필수입니다.

**PCA**는 고차원 데이터를 정보 손실을 최소화하며 저차원으로 압축하는 방법으로, 데이터의 분산이 가장 큰 방향(축)을 순서대로 찾아 그 축들로 데이터를 투영합니다. 데이터를 평균 0으로 중심화한 뒤 공분산행렬을 계산하고, 그 고유값 분해에서 고유값이 큰 순서대로 고유벡터(주성분)를 골라 상위 몇 개에 투영합니다. 선형 변환이라 계산이 빠르고 해석이 가능하며, 고유벡터들이 서로 직교해 주성분들끼리 독립적인 정보를 담게 됩니다. 다만 비선형 구조는 왜곡될 수 있어 이런 경우 t-SNE·UMAP·오토인코더가 대안이 됩니다.

고차원 데이터를 K-means로 바로 군집화하면 차원의 저주 때문에 거리 계산이 무의미해지는 경우가 많습니다. 그래서 실무에서는 PCA로 먼저 차원을 축소한 뒤(예: 1000차원을 20차원으로), 그 축소된 공간에서 K-means를 수행하고, 필요하면 2~3차원까지 추가로 축소해 결과를 시각화하는 순서로 함께 사용합니다. PCA는 "연속적인 선형 부분공간"으로, K-means는 "이산적인 점들의 집합"으로 데이터를 근사한다는 점에서, 같은 압축 철학의 두 극단이라 볼 수 있습니다.

## 8. 모델을 어떻게 고를까: 선택 기준

**1단계: 문제 유형 확정.** 레이블(정답)이 있으면 지도학습(회귀 또는 분류), 없으면 비지도학습(군집화·차원 축소·이상치 탐지·밀도 추정)입니다. 예측 대상이 연속값이면 회귀, 범주면 분류입니다.

**2단계: 선택 기준들**

- **데이터 규모**: 데이터가 적으면(수백~수천 건) 선형모델·KNN·결정트리처럼 단순한 모델을, 데이터가 많으면(수만 건 이상) 랜덤포레스트·그래디언트부스팅·신경망처럼 복잡한 모델을 고려합니다.
- **해석 가능성 vs 성능**: 금융 심사나 의료 진단처럼 의사결정 근거를 설명해야 하는 경우는 선형모델·단일 결정트리가 유리하고, 추천이나 이미지 인식처럼 성능이 최우선인 경우는 랜덤포레스트·그래디언트부스팅·신경망이 유리합니다.
- **선형성/비선형성**: 관계가 대체로 선형이면 선형모델로 충분하고, 복잡한 비선형·상호작용 관계라면 트리 기반 앙상블·KNN·신경망을 고려합니다.
- **특징 스케일 민감도**: 거리 기반 모델(KNN, K-means, PCA)은 스케일링이 필수지만, 트리 기반 모델은 분할 기준이 순서만 보므로 스케일링이 불필요합니다.
- **계산 비용/속도**: KNN은 학습은 빠르지만 예측이 느리고, 선형모델·트리 기반은 학습은 오래 걸릴 수 있지만 예측이 빠릅니다.
- **클래스 불균형**: 극심한 불균형은 일반 분류보다 이상치 탐지 관점으로 접근하거나 클래스 가중치·리샘플링을 병행합니다.
- **차원 수**: 특징이 매우 많고 상관관계가 크면 먼저 차원 축소로 정리한 뒤 모델링하고, 차원이 높고 희소한 데이터(텍스트 등)에는 정규화가 강한 선형모델이 의외로 강력합니다.

**3단계: 실전 워크플로우.** 가장 단순한 모델(회귀는 선형회귀, 분류는 로지스틱회귀)로 성능 기준선을 확보한 뒤, 결정트리 → 랜덤포레스트·그래디언트부스팅 순으로 비선형 모델로 개선을 시도합니다. 교차검증으로 일반화 성능을 확인하면서 편향-분산 트레이드오프를 점검합니다. 학습 성능은 높은데 검증 성능이 낮다면 과적합(분산이 큼)이므로 정규화·가지치기·데이터 증강을, 둘 다 낮다면 과소적합(편향이 큼)이므로 더 복잡한 모델이나 특징 추가를 시도합니다. 마지막으로 하이퍼파라미터 탐색과 여러 모델의 앙상블로 성능을 다듬습니다.
