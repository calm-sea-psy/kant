## 1. 편향, 분산, 과소적합, 과적합

**편향(Bias)**은 모델이 너무 단순한 가정을 해서 실제 데이터의 패턴을 제대로 못 잡는 정도입니다. 편향이 높다는 것은 모델이 지나치게 단순하다는 뜻이며(예: 복잡한 곡선 데이터를 직선으로 예측), 이 경우 훈련 데이터조차 잘 맞추지 못합니다.

**분산(Variance)**은 모델이 훈련 데이터의 미세한 변화나 노이즈에 얼마나 민감하게 반응하는지입니다. 분산이 높다는 것은 모델이 훈련 데이터 하나하나에 너무 민감하다는 뜻이며, 훈련 데이터를 조금만 바꿔도 예측 결과가 크게 달라집니다. 이 경우 훈련 데이터는 완벽히 맞추지만 새로운 데이터에서는 성능이 확 떨어집니다.

**과소적합(Underfitting)**은 편향이 높을 때 발생하는 현상으로, 모델이 너무 단순해서 데이터의 패턴 자체를 학습하지 못해 훈련 성능도, 테스트 성능도 모두 나쁩니다(예: 비선형 데이터에 단순 선형회귀를 적용). 해결책은 모델 복잡도를 높이거나(특성 추가, 더 깊은 모델), 규제를 완화하거나, 학습을 더 오래 시키는 것입니다.

**과적합(Overfitting)**은 분산이 높을 때 발생하는 현상으로, 모델이 너무 복잡해서 훈련 데이터의 노이즈까지 외워버려 훈련 성능은 매우 좋지만 테스트 성능은 나쁩니다(예: 데이터 포인트가 적은데 매우 고차원의 다항식을 억지로 맞추는 경우). 해결책은 데이터를 늘리거나, 규제(L1, L2)를 적용하거나, 드롭아웃·조기종료를 쓰거나, 모델을 단순화하거나, 교차검증을 활용하는 것입니다.

**편향-분산 트레이드오프**: 편향과 분산은 보통 반비례 관계입니다. 모델 복잡도가 낮으면 편향은 높고 분산은 낮아(과소적합) 지고, 복잡도가 높으면 편향은 낮고 분산은 높아(과적합)집니다. 모델을 복잡하게 만들면 편향은 줄지만 분산이 커지고, 단순하게 만들면 분산은 줄지만 편향이 커집니다. 머신러닝 모델링의 목표는 이 둘의 합(총 오차)이 최소가 되는 적절한 지점을 찾는 것입니다.

## 2. 기대 예측오차의 세 가지 구성요소

모델의 기대 예측오차는 편향에서 비롯된 오차, 분산에서 비롯된 오차, 그리고 어떤 모델을 쓰든 절대 줄일 수 없는 데이터 자체의 본질적인 잡음, 이렇게 세 부분으로 나누어 이해할 수 있습니다.

- **편향 요소**: 여러 번 학습했을 때 평균 예측이 참값에서 얼마나 벗어나는가(모델의 표현력 부족)
- **분산 요소**: 훈련셋이 바뀔 때마다 예측이 얼마나 요동치는가(모델의 데이터 민감도)
- **본질적 잡음**: 어떤 모델을 쓰든 절대 줄일 수 없는, 데이터 자체가 가진 오차

과소적합은 편향 요소가 큰 상태, 과적합은 분산 요소가 큰 상태입니다. 총 기대오차를 줄이려면 편향과 분산 요소의 합을 최소화해야 하고, 이 둘은 보통 모델 복잡도에 대해 반대 방향으로 움직입니다.

## 3. 학습곡선(Learning Curve)

학습곡선은 가로축을 훈련 데이터 크기(또는 epoch), 세로축을 오차(손실)로 놓고, 훈련 오차 곡선과 검증 오차 곡선을 함께 그려서 봅니다. 이 곡선에서 세 가지 특징을 읽으면 편향·분산 문제를 진단할 수 있습니다.

- **높이(Height)**: 두 곡선이 결국 도달하는 절대적인 오차 수준. 훈련 오차의 최종 높이가 여전히 높다면, 모델이 훈련 데이터조차 잘 못 맞추는 것이므로 편향이 높다는 신호입니다. 두 곡선이 모두 높은 위치에서 평평하게 붙어 있으면 전형적인 과소적합 패턴입니다.
- **간격(Gap)**: 훈련 오차와 검증 오차 사이의 세로 거리. 간격이 크면 훈련 데이터에는 잘 맞지만 새 데이터에서는 성능이 뚝 떨어진다는 뜻이므로 분산이 높다는(과적합) 신호입니다. 간격이 작으면 분산 문제는 적다는 뜻이며, 이 경우 남은 문제는 높이(편향) 쪽을 봐야 합니다.
- **끝부분 기울기(End-tail Slope)**: 훈련 데이터 양을 계속 늘려갈 때, 곡선의 끝쪽이 아직 가파르게 움직이는지 이미 평평해졌는지를 봅니다. 검증 오차 곡선이 끝부분에서도 여전히 가파르게 감소 중이라면 아직 수렴하지 않은 것이라 데이터를 더 모으면 성능이 개선될 여지가 큽니다. 끝부분 기울기가 거의 평평하다면 이미 수렴해 포화 상태이므로, 데이터를 더 모아도 소용없고 모델 구조·특성·정규화를 바꿔야 합니다.

높이는 편향을, 간격은 분산을, 끝부분 기울기는 "지금 시점에서 데이터를 더 모으는 것이 실제로 효과가 있을지"를 알려주는 지표입니다. 데이터 수집은 비용이 크기 때문에, 끝기울기 확인은 자원 배분 관점에서 특히 중요합니다.

## 4. 검증곡선(Validation Curve)

검증곡선은 학습곡선과 짝을 이루는 진단 도구이지만 가로축이 다릅니다. 학습곡선의 가로축이 "훈련 데이터 크기"로 "데이터를 얼마나 더 모아야 하는가"를 진단한다면, 검증곡선의 가로축은 "모델의 하이퍼파라미터(복잡도)"로 "모델을 얼마나 복잡하게 해야 하는가"를 진단합니다.

훈련 오차는 모델이 복잡해질수록 거의 계속 감소하는 경향을 보입니다(더 복잡한 모델일수록 훈련 데이터를 더 잘 외울 수 있으므로). 반면 검증 오차는 처음엔 감소하다가 어느 지점을 지나면 다시 증가하는 U자형 곡선을 그립니다.

- **왼쪽(복잡도 낮음)**: 훈련 오차, 검증 오차 둘 다 높고 간격은 작음 → 과소적합(편향 문제)
- **중간(최적 지점)**: 검증 오차가 최소가 되는 지점 → 적절
- **오른쪽(복잡도 높음)**: 훈련 오차는 계속 낮아지지만 검증 오차는 다시 올라가 간격이 벌어짐 → 과적합(분산 문제)

검증곡선의 U자 바닥이 이론적으로 가장 좋은 복잡도이며, 현재 설정이 U자 곡선의 어느 쪽에 있는지 보고 왼쪽이면 복잡도를 올리고 오른쪽이면 낮추는 식으로 조정 방향을 정합니다.

검증곡선으로 먼저 "지금 모델이 너무 단순한지 복잡한지"를 파악해 적절한 복잡도를 고르고, 그다음 학습곡선으로 "이 복잡도에서 데이터를 더 모으면 도움이 되는지"를 확인하는 식으로 두 도구를 상호보완적으로 함께 씁니다. 즉 검증곡선은 "모델을 조정할지"를, 학습곡선은 "데이터를 더 모을지"를 결정하는 데 특화된 도구입니다.

## 5. Train/Validation 성능과 Train-Valid Gap, Fold

**Train 성능**은 모델이 학습에 직접 사용한 데이터에 대해 얼마나 잘 맞추는가를, **Validation 성능**은 학습에 쓰지 않은 데이터에 대해 얼마나 잘 맞추는가를 보여줍니다. Train 성능은 모델의 학습 능력을, Validation 성능은 모델의 일반화 능력을 나타내며, 실제로 관심 있는 것은 처음 보는 데이터에서의 성능이므로 Validation 성능이 실질적인 판단 기준이 됩니다.

**Train-Valid Gap**은 두 성능(또는 오차)의 차이로, 분산을 실제 데이터로 근사 측정한 값이라 볼 수 있습니다. Gap이 작고 둘 다 성능이 비슷하면 분산 문제는 적으며 Train 성능 자체가 낮으면 편향(과소적합) 문제, Gap이 크면(Train이 Valid보다 훨씬 좋으면) 분산이 큰 과적합, Gap이 거의 없고 둘 다 나쁘면 과소적합, Gap이 거의 없고 둘 다 좋으면 이상적인 상태입니다.

**Fold**는 데이터를 나눈 하나의 분할 단위입니다. 단순히 train/validation을 한 번만 나누면 그 나누는 방식(운)에 따라 성능 추정치가 우연히 좋거나 나쁘게 나올 수 있는데, 이 문제를 줄이기 위한 방법이 k-fold 교차검증입니다. 전체 데이터를 k개의 동일한 크기 조각으로 나눈 뒤, 매번 1개 fold를 validation으로, 나머지를 train으로 써서 학습·평가하는 과정을 k번 반복하고 이 k번의 결과를 평균 내어 최종 성능 추정치로 삼습니다. k 값이 클수록 각 fold의 train 크기가 커져 편향은 줄지만, fold 간 겹치는 데이터가 많아져 fold별 결과의 상관이 커지고 계산 비용도 커집니다. 극단적으로 fold 개수를 데이터 개수만큼 두면 LOOCV(Leave-One-Out CV)라 부르며, 분류 문제에서는 각 fold의 클래스 비율을 원본과 비슷하게 유지하는 방식(Stratified k-fold)을 많이 씁니다.

## 6. Train AP vs Validation AP

Train AP는 학습에 사용한 데이터에 대해 계산한 평균 정밀도(AP)이고, Validation AP는 학습에 쓰지 않은 held-out 데이터에 대해 계산한 값입니다. 둘의 차이(Gap)가 작고 둘 다 높으면 일반화가 잘 된 이상적인 상태, 작고 둘 다 낮으면 편향이 높은 과소적합(모델·특성·학습량 부족), Gap이 크면(Train이 Validation보다 훨씬 높으면) 분산이 큰 과적합(훈련 데이터의 패턴이나 노이즈를 외운 상태)입니다.

객체 탐지 문제에서 이 Gap이 크게 벌어지는 흔한 원인으로는 훈련 데이터 양이 적거나 특정 장면·객체 유형에 편중된 경우, 데이터 증강 부족, 데이터에 비해 과한 모델 용량, 정규화(가중치 감쇠, 드롭아웃 등) 부족이 있습니다.

## 7. 과적합·과소적합 대응 전략

문제를 고편향 후보인지 고분산 후보인지 진단한 뒤, 그에 맞는 처방을 적용하는 흐름입니다.

**고편향(High Bias) 후보**: Train 성능 자체가 낮고 Train-Valid gap은 작습니다. 학습곡선·검증곡선에서 "높이"가 높은 상태로, 모델이 훈련 데이터조차 잘 설명하지 못하는 과소적합입니다. 이는 모델이 데이터의 실제 패턴을 표현할 능력 자체가 부족한 상태로, 아무리 학습을 더 시켜도 "그릴 수 있는 함수의 형태"가 데이터의 진짜 구조보다 단순하기 때문에 한계가 있습니다. 대응 방향은 모델의 표현력을 키우는 쪽으로, 모델 복잡도를 높이거나(더 깊은 네트워크, 더 많은 트리), 특성을 추가하거나, 규제 강도를 오히려 낮추거나, 학습을 더 오래 시키는 것입니다.

**고분산(High Variance) 후보**: Train 성능은 좋은데 Validation 성능이 크게 떨어져 gap이 큽니다. 학습곡선에서 "간격"이 크고, 검증곡선의 복잡도 높은 쪽에 위치한 과적합입니다. 이는 모델이 데이터의 진짜 패턴뿐 아니라 훈련 데이터에만 있는 노이즈나 우연한 패턴까지 외워버린 상태로, 훈련셋이 조금만 바뀌어도 예측이 크게 달라집니다. 대응 방향은 모델을 제약하거나 데이터를 늘리는 쪽으로, 훈련 데이터를 추가하거나(가장 근본적인 해결책), 규제를 강화하거나, 조기 종료를 쓰거나, 모델을 단순화·드롭아웃·데이터 증강을 적용하거나, 앙상블(배깅 등)을 활용하는 것입니다.

**규제(Regularization)**는 모델이 훈련 데이터를 "너무 잘" 맞추지 못하도록 손실 함수에 페널티를 추가해, 파라미터가 과도하게 커지거나 복잡한 형태를 갖지 못하게 제약하는 기법입니다. 규제는 분산을 줄이는 대신 편향을 약간 늘리는 트레이드오프 조작이므로, 이미 고편향 상태인 모델에 규제를 더 걸면 오히려 상황이 악화됩니다.

**조기 종료(Early Stopping)**는 학습을 진행하면서 매 epoch마다 validation 성능을 함께 관찰하다가, validation 성능이 더 이상 좋아지지 않고 오히려 나빠지기 시작하는 시점에서 학습을 멈추는 기법입니다. 학습이 진행될수록 모델은 점점 더 복잡한 패턴(결국 노이즈까지)을 학습하게 되는데, 이는 암묵적으로 모델 복잡도를 늘리는 것과 같은 효과를 냅니다. 그래서 조기 종료는 사실상 "epoch 수를 규제 대상으로 삼는 규제 기법"이라 볼 수 있으며, 별도의 페널티 항 없이도 분산을 억제할 수 있는, 실무에서 가장 손쉽고 계산 비용이 적게 드는 과적합 방지 기법 중 하나입니다.

## 8. 규제: L1(Lasso), L2(Ridge), ElasticNet

규제는 모델의 손실 함수에 파라미터 크기에 대한 페널티 항을 추가해, 모델이 훈련 데이터를 지나치게 정교하게 맞추지 못하도록 제약하는 기법입니다.

직관적으로, 파라미터(가중치) 값이 클수록 모델이 입력의 작은 변화에도 출력을 크게 흔들 수 있습니다. 예를 들어 고차 다항식 회귀에서 과적합된 모델은 데이터 포인트 사이사이를 요동치며 지나가는데, 이때 계수들이 매우 큰 값을 갖게 됩니다. 이런 큰 계수들을 억제하면 곡선이 완만해지고, 훈련셋이 조금 바뀌어도 예측이 크게 흔들리지 않게 되어 분산이 줄어듭니다. 대신 데이터를 완벽히는 못 맞추게 되니 편향은 약간 늘어나는 트레이드오프가 생깁니다.

**L1(Lasso)**은 계수들의 절댓값 합에 페널티를 주어, 일부 계수를 정확히 0으로 만듭니다(성긴 해). 반복적인 최적화 방법으로 풀어야 하며, 결과적으로 중요하지 않은 특성의 계수를 0으로 만들어 사실상 모델에서 제거하는 자동 특성 선택 효과가 있습니다. 다만 상관관계가 높은 특성 그룹이 있으면 그중 하나만 남기고 나머지는 0으로 만드는 경향이 있어 선택이 불안정할 수 있습니다.

**L2(Ridge)**는 파라미터 제곱합에 페널티를 부여해, 모든 계수를 고르게 축소시키되 정확히 0으로 만들지는 않습니다. 계산이 닫힌 형태(공식으로 한 번에 계산 가능)로 존재해 수치적으로 안정적입니다. 상관관계가 높은 특성들이 있으면 그 계수들을 비슷한 크기로 나눠 분담시키는 경향이 있습니다.

**ElasticNet**은 L1과 L2를 가중 결합한 방식입니다. Lasso는 특성 수가 샘플 수보다 많은 고차원 상황에서 선택할 수 있는 계수 개수에 한계가 있고, 상관관계 높은 특성 그룹 중 하나만 임의로 선택해버리는 불안정성이 있습니다. ElasticNet은 L2 항을 섞어 상관관계 높은 특성들을 그룹으로 함께 선택(0으로 만들거나 살리거나)하면서도 L1의 성긴 해 효과는 유지해, 두 방식의 장점을 절충합니다.

정리하면, 계수 축소 방식은 Ridge가 고르게, Lasso가 일부를 0으로, ElasticNet이 그룹 단위로 절충합니다. 특성 선택 효과는 Ridge는 없고, Lasso는 자동으로 있으며, ElasticNet은 그룹 단위로 있습니다. 다중공선성(특성 간 강한 상관관계)에는 Ridge와 ElasticNet이 강건하고 Lasso는 불안정할 수 있습니다. 계산 방식은 Ridge만 공식으로 한 번에 풀리고, Lasso와 ElasticNet은 반복 최적화가 필요합니다.

특성이 다 유의미하고 다중공선성이 문제라면 Ridge를, 특성이 많고 그중 일부만 진짜 중요할 것 같으며 해석 가능한(단순한) 모델이 필요하다면 Lasso를, 특성 수가 샘플 수보다 많거나 상관관계 높은 특성 그룹이 있는데도 성긴 해가 필요하다면 ElasticNet을 선택합니다. 규제 강도는 앞서 설명한 검증곡선과 k-fold 교차검증으로 튜닝하는 것이 일반적입니다.

## 9. 하이퍼파라미터: 규제 강도와 L1·L2 배합 비율

**규제의 세기를 정하는 하이퍼파라미터**는 규제를 얼마나 강하게 걸지를 결정하며, Ridge·Lasso·ElasticNet 셋 다 공통으로 갖습니다. 이 값이 0이면 규제가 없는 것과 같아(원래 손실함수와 동일) 과적합 위험이 있고, 값이 커질수록 계수들이 점점 더 강하게 0쪽으로 눌려 과소적합 위험이 커집니다. 검증곡선의 가로축이 바로 이 값이며, 보통 로그 스케일(0.001, 0.01, 0.1, 1, 10 등)로 탐색합니다.

**L1과 L2의 배합 비율을 정하는 하이퍼파라미터**는 ElasticNet에서만 등장하며, 값이 1에 가까울수록 순수 Lasso(L1만)에, 0에 가까울수록 순수 Ridge(L2만)에 가까워지고, 중간값이면 둘을 절반씩 섞은 형태가 됩니다. Ridge나 Lasso를 단독으로 쓸 때는 애초에 섞을 것이 없으므로 이 배합 비율 자체가 필요 없습니다.

두 하이퍼파라미터의 의미를 비유하면, 규제 세기는 "브레이크를 얼마나 세게 밟을지"에 해당하고, 배합 비율은 "그 브레이크가 앞바퀴(L1)와 뒷바퀴(L2) 중 어느 쪽에 더 실릴지"를 정하는 것과 비슷합니다. 규제 세기는 Ridge·Lasso·ElasticNet 모두에 적용되고 보통 검증곡선(U자)에서 최소점을 탐색해 정하는 반면, 배합 비율은 ElasticNet에만 적용되고 보통 규제 세기와 함께 그리드 탐색으로 정합니다.
